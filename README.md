# CVAT Sidebar Shortcuts

현재 소스 버전: **2.15.5** · Chrome Manifest V3 확장프로그램

CVAT의 AI·새 마스크·폴리곤·회전 사각형·스켈레톤 도구 단축키, 라벨 선택·숨김 오버레이, 1도 화면 회전·수평 격자, 라벨 찾기·필수 라벨 누락 검수와 일괄 편집, 붙여넣기 반복, Space 화면 이동, 개인 연결 상태 확인과 한글 가이드를 제공합니다.

## 스켈레톤 location 일괄 변경

1. 오버레이 **화면 → 스켈레톤 location 일괄 변경**을 엽니다.
2. **tag / sticker** 중 원하는 값을 고르고 **변경 대상 검사**를 누릅니다. 선택지는 현재 Job 라벨의 실제 `location` 속성 정의에서 읽습니다.
3. 변경할 개수, 이미 같은 값인 개수와 제외 사유를 확인하고 **Job 전체에 적용**합니다.
4. CVAT에서 결과를 확인한 뒤 **저장**합니다. 되돌리기는 객체별로 적용되며 CVAT 자동 저장 설정은 그대로 적용됩니다.

현재 Job의 모든 프레임에 있는 스켈레톤 **Shape의 부모 location 속성**을 변경합니다. 그룹화 여부와 관계없이 동작하고 숨김·필터에 가려진 객체도 포함합니다. 좌표·그룹·다른 속성·관절 속성은 유지합니다. 잠금·보호 객체, 삭제 프레임, Track, `location` 또는 선택값이 없는 라벨은 제외해 표시합니다. 이미 같은 값은 다시 변경하지 않습니다.

검사 후 주석·잠금·속성 정의가 바뀌거나 5분이 지나면 다시 검사합니다. 최대 2,000개 대상 프레임·20,000개 스켈레톤 Shape를 처리하고 목록은 처음 100건을 표시합니다. 직접 저장 API를 호출하거나 이미지 데이터를 가져오지 않습니다.

## 박스·폴리곤·스켈레톤 자동 그룹화

1. 오버레이 **화면 → 박스·폴리곤·스켈레톤 자동 그룹화**에서 **현재 프레임** 또는 **현재 Job 전체**를 선택합니다.
2. **그룹 대상 검사**로 도형·스켈레톤 ID, 기존 그룹 추가 여부와 제외 사유를 확인합니다.
3. **매칭된 대상 그룹화**를 누르고 결과를 확인한 뒤 CVAT에서 **저장**합니다.

스켈레톤 관절의 가로·세로 최소/최대 좌표로 계산한 **중심점 또는 관절 하나 이상**이 들어간 도형을 연결합니다. 이미지 가장자리에서 중심이 도형 밖에 있어도 일부 관절이 안에 있으면 매칭합니다. 박스가 있으면 **폴리곤 + 박스 + 스켈레톤**, 없으면 **폴리곤 + 스켈레톤**을 묶습니다. 박스만 있는 기존 작업은 박스 + 스켈레톤으로 처리합니다. 한 도형에 여러 스켈레톤이 있거나 같은 스켈레톤을 여러 도형이 포함하면 연결된 전체를 한 그룹으로 묶습니다. 빈 도형은 그대로 둡니다.

기존 그룹 번호, 다른 프레임의 그룹 구성, 일부 관절의 경계 돌출 때문에 제외하지 않습니다. 검사 범위에서 매칭된 객체만 **새 그룹 번호**로 이동하고 다른 프레임·비대상 객체의 기존 그룹 번호는 유지합니다. 이미 대상 전체가 같은 그룹이면 중복 적용하지 않습니다. 검사 목록에서 객체 ID와 기존 그룹 번호를 확인할 수 있고 CVAT 되돌리기는 그룹별로 적용됩니다.

자기 교차·중복 꼭짓점 폴리곤도 CVAT SVG의 nonzero 채움 규칙으로 검사하며 원본 좌표는 수정하지 않습니다. 잠금·보호 객체·Track은 제외합니다. 읽을 수 없는 좌표·미지원 회전·1,001개를 초과하는 꼭짓점은 해당 도형만 제외하고 ID와 사유를 표시합니다. 나머지 도형의 검사는 계속합니다. 원본 좌표·라벨·객체 수는 유지하고 숨김·필터에 가려진 객체도 검사합니다. 삭제 프레임은 제외하며 최대 2,000개 대상 프레임/5,000그룹, 목록은 처음 100건 표시입니다. 검사 후 변경 또는 5분 만료 시 다시 검사합니다.

## 라벨 숨김 · 1도 화면 회전 · 격자

- **라벨 선택 탭 → 라벨 옆 눈 버튼**: 해당 Job의 라벨을 숨기거나 다시 표시합니다. 프레임을 이동해도 적용하며 Job별로 이 브라우저에 기억합니다. 그릴 라벨 선택과는 별개입니다.
- **화면 탭 → −1° / +1° / 각도 입력 → 적용**: 현재 프레임의 표시 각도를 조절합니다. **0° 복귀**로 바로 되돌립니다. 프레임별 각도는 현재 CVAT 세션에서 유지됩니다.
- **화면 탭 → 격자 표시**: 화면에 고정된 수평·수직 격자를 켭니다. 간격·선명도·색상을 조절할 수 있습니다.
- 바코드 선을 격자에 맞추고 스켈레톤 단축키로 시작하세요. 새 생성 틀은 화면 수평·수직을 유지합니다. 두 모서리 클릭 또는 드래그로 완성한 관절을 원본 이미지 좌표로 변환합니다. 각도 조절은 그리기·편집·재생을 마친 상태에서 합니다.
- 미세 회전 중 브러쉬·AI로 전환하면 좌표 호환을 위해 0°로 복귀합니다. 회전은 원본 이미지나 객체 좌표를 수정하지 않습니다.
- **숨김 모두 해제**는 확장이 숨긴 라벨을 복구합니다. CVAT에서 수동으로 숨겼던 객체는 유지합니다. 표시 설정은 내 브라우저에만 적용됩니다.

## 회전 사각형 · 스켈레톤 단축키

1. 확장 팝업 **도구 단축키**에서 **회전 사각형** 또는 **새 스켈레톤 → 지정**을 눌러 사용할 키를 정합니다. 새 키는 미지정이며 기존 설정을 유지합니다.
2. 사각형·스켈레톤은 CVAT 도구에 지정된 고정 라벨을 그대로 사용합니다. 오버레이에서 라벨을 바꿀 필요가 없습니다.
3. 회전 사각형 키는 Esc → 사각형 메뉴 → **Rotated → Shape** 순서로 시작합니다. Drawing method를 수동으로 바꿨어도 단축키 실행 때 Rotated를 다시 선택합니다.
4. 스켈레톤 키는 Esc → 스켈레톤 메뉴 → **Shape** 순서로 시작합니다. Track은 선택하지 않습니다.

이 두 도구는 라벨 선택창을 열거나 라벨을 변경하지 않습니다. N으로 다시 불러올 때도 CVAT가 기억한 라벨을 유지합니다. AI·마스크·폴리곤의 오버레이 라벨 연동은 계속 사용할 수 있습니다. 회전 사각형을 지원하지 않거나 Rotated 선택이 반영되지 않는 CVAT에서는 다른 방식으로 대체하지 않습니다. CVAT의 OpenCV 준비 시간·오류는 기존 CVAT 화면에서 확인하세요.

## 작업 오버레이

2.7.1에서 Job 이동 후 연결 상태 조회가 계속 실패하던 오류를 수정했습니다. 자동 측정은 새 Job에서 이어 시작하고, 수동 모드는 새 Job에서 측정 시작을 누릅니다. 이전 Job 통계는 초기화합니다. [수정 및 검증 보고서](reports/navigation-2.7.1.md).

- CVAT 탭에서 확장을 켜면 기존 라벨 선택창에 **라벨 선택 / 검수 / 연결 상태** 탭이 나타납니다. 같은 창에서 내용만 전환합니다.
- 상단 드래그, 모든 가장자리 크기 조절, 하단 투명도, 최소화 및 완전히 닫기를 그대로 사용합니다. 작은 창은 스크롤하고 넓은 창은 라벨 목록이 여러 열로 늘어납니다.
- 팝업의 검수·연결 상태 화면에서 **작업 화면에서 열기**를 눌러 바로 열 수 있습니다. 팝업 기능도 유지하며 같은 Job의 선택·결과·통계를 공유합니다.
- 검수는 CVAT에 저장한 작업을 기준으로 실행합니다. 다른 Job으로 이동하면 이전 결과를 새 Job의 결과처럼 보여주지 않습니다.
- 연결 상태의 최초 사이트 권한은 팝업에서 허용합니다. 이후에는 오버레이에서도 측정·자동 측정·오류 알림을 조작합니다. 창을 닫거나 최소화해도 켜진 측정은 계속되며, 숨긴 화면의 주기적 UI 갱신은 멈춥니다.

## 특정 라벨이 있는 프레임 찾기

1. 팝업 또는 작업 오버레이의 **검수 → 누락·라벨 찾기**를 엽니다.
2. `person` 등 확인할 라벨을 체크하고 CVAT에서 작업을 저장합니다.
3. **CVAT에서 작업을 저장했어요 → 선택 라벨 찾기**를 누릅니다.
4. **확인할 라벨 프레임**에서 번호를 누르거나 **이전/다음 결과로 이동**으로 차례대로 봅니다. 목록은 30개씩 표시합니다.
5. 여러 라벨을 선택하면 하나라도 있는 프레임을 모아 표시합니다. 아래 필터로 특정 라벨만 볼 수 있으며 결과 복사·CSV 저장도 지원합니다.

현재 Job의 저장된 Shape와 Track을 조회합니다. 삭제 프레임과 Outside 구간은 제외합니다. 같은 프레임에 객체가 여러 개 있어도 프레임은 한 번만 세며, 누락 검사와 가장 최근 결과를 공유합니다. 작업 수정 후 저장하고 다시 검색하세요.

## 필수 라벨 누락 검수

1. CVAT의 현재 Job에서 확장 팝업을 열고 **검수** 탭을 누릅니다. 단축키 기능 활성화와 독립적으로 사용할 수 있습니다.
2. 모든 프레임에 최소 하나 있어야 하는 라벨을 체크합니다. 선택은 서버 origin과 Job별로 기억합니다.
3. CVAT에서 작업을 저장한 뒤 **CVAT에서 작업을 저장했어요 → 누락 프레임 검사**를 누릅니다.
4. `D가 없는 프레임: 45`처럼 라벨별 결과를 확인합니다. 프레임 번호 클릭 또는 **이전/다음 누락으로 이동**으로 해당 화면을 엽니다. 라벨별 필터와 30개 단위 목록을 제공합니다.
5. 수정하고 CVAT에서 저장한 뒤 다시 검사합니다. **결과 복사 / CSV 저장**으로 기록을 가져갈 수 있습니다.

조회는 현재 로그인한 CVAT 서버의 Job, 라벨, 프레임 메타데이터, 저장된 주석 API를 사용합니다. 이미지를 읽거나 외부로 전송하지 않습니다. 마지막 결과의 라벨 이름·ID·색상·누락 프레임·검사 시각은 Chrome 로컬 저장소에 보관하며 좌표·마스크·속성은 보관하지 않습니다. 검사를 시작하면 팝업을 닫아도 완료 결과가 저장됩니다. 페이지를 새로고침하거나 Job을 바꾸면 완료되지 않은 검사는 다시 실행해야 합니다.

Shape와 Track의 Outside 구간, 삭제 프레임, 원본 영상의 frame step을 반영합니다. Tag는 그린 객체로 세지 않으며, Skeleton Track은 검사 실패로 안내합니다. 객체 수·모양·세부 누락은 검사하지 않습니다. 전체 프레임에 존재하지 않는 것이 정상인 라벨은 필수로 선택하지 마세요. 검사 범위는 최대 20만 프레임·200개 라벨 및 1천만 프레임-라벨 조합이며 원본 응답은 64MB, 저장 결과는 2MB, CSV는 누락 항목 20만 행으로 제한합니다.

조회 실패는 정상으로 처리하지 않습니다. 검사는 저장된 작업의 한 시점이며 자동으로 최신화하지 않습니다. 프레임 이동은 CVAT의 기존 입력칸을 사용하고 그리기·재생·저장 중에는 차단합니다. 내부 연결을 지원하지 않는 CVAT에서는 번호를 직접 입력해 이동할 수 있습니다.

## 검수에서 삭제·라벨 변경

팝업 또는 작업 오버레이의 **검수 → 삭제·라벨 변경**에서 사용합니다.

1. 먼저 현재 CVAT 작업을 저장하고 그리기·재생을 마칩니다.
2. **편집할 라벨 → 선택 라벨 스캔**을 누릅니다. 해당 라벨이 있는 프레임과 객체 수를 새로 확인합니다. 여러 라벨을 고르면 하나라도 있는 프레임을 보여줍니다. 프레임 목록은 30개씩 표시합니다.
3. 프레임 번호·구간에 `3, 7, 20~40`을 입력하거나 **검색된 전체 (현재 Job)**를 선택합니다. CVAT 화면의 프레임 번호 기준이며 시작과 끝을 모두 포함합니다.
4. **객체 삭제** 또는 **다른 라벨로 변경**을 선택합니다. 변경할 때는 새 라벨도 선택합니다.
5. **대상 확인**에서 Job·라벨·범위·객체 수를 보고, 확인 체크 후 적용합니다.
6. CVAT 화면의 결과를 확인하고 저장합니다. 편집 후 이전 검수 결과는 지워지므로 저장 후 다시 검사하세요.

누락 검수와 같은 탭에 있지만 편집은 선택한 라벨을 새로 스캔합니다. 필수 라벨 체크나 누락 결과를 편집 대상으로 가져오지 않습니다. 선택 라벨이 바뀌면 스캔 결과를 초기화합니다. 스캔 후 데이터 변경·5분 만료·Job 이동 시 다시 스캔하세요. HTTP 사내 CVAT에서도 확인용 ID를 생성할 수 있도록 수정했습니다.

클래스 목록은 유지하며 선택한 라벨의 그린 객체만 처리합니다. 숨김·필터에 가려진 객체도 포함합니다. Shape는 지정 구간·전체에서 지원하고, 선택 라벨에 Track이 있으면 **검색된 전체 (현재 Job)**에서만 허용합니다. Track 프레임 목록은 Outside 구간을 제외하고 편집은 Track 단위로 적용합니다. Tag는 제외하며 Skeleton·잠금·보호 객체는 차단합니다. 다른 Job의 객체는 대상이 아닙니다. 라벨을 바꾸면 속성은 CVAT의 새 라벨 기본값 규칙을 따릅니다. 삭제된 프레임에 객체 정보가 남으면 스캔 목록에 포함될 수 있고, 대상 객체를 읽지 못하면 적용하지 않습니다.

현재 페이지의 CVAT 객체 API와 변경 이력을 이용합니다. 직접 서버에 삭제·수정 요청을 보내거나 자동으로 저장하지 않지만, 켜져 있는 CVAT 자체 자동 저장은 계속 적용됩니다. 실행 중 실패하면 일부가 적용됐을 수 있으므로 결과와 CVAT 되돌리기를 확인하세요. 되돌리기는 객체별로 여러 번 필요할 수 있습니다. 확인 후 데이터 변경·5분 만료·Job 이동은 재확인이 필요합니다. 최대 20,000개 객체·조회 프레임 및 직렬화 문자열 약 3,355만 자까지 처리합니다. 내부 연결을 확인할 수 없는 CVAT 버전에서는 적용하지 않습니다.

## 붙여넣기 반복 사용법

1. 객체 하나를 직접 그리고 CVAT에서 `Ctrl+C`로 복사합니다.
2. **처음 붙여넣을 프레임**으로 이동합니다. 원본을 그린 프레임에서 실행하면 그 프레임에도 하나 더 붙습니다.
3. 팝업에서 확장을 켜고 **붙여넣기 반복 → 지정**으로 시작 키를 정합니다. 팝업의 **반복 시작** 버튼으로도 시작할 수 있습니다.
4. `Ctrl+V → 왼클릭 확정 → F`가 반복됩니다. **Esc** 또는 실행 키를 다시 누르면 중지합니다. 마우스 이동이나 다른 조작, 탭 전환, 마지막 프레임, 확인 실패 시에도 멈춥니다.
5. 결과를 확인한 뒤 CVAT에서 직접 저장합니다. 알림은 시작·중지·오류 때만 표시됩니다.

복사한 Shape 객체 하나를 사용합니다. 확장 라벨 선택은 적용하지 않습니다. 프레임마다 미리보기 준비·객체 추가·다음 프레임 로딩을 확인하고, 다음 반복까지 0.5초 기다립니다. 각 단계가 15초 안에 확인되지 않으면 반복을 중지하며 자동 재시도하지 않습니다. 실행 상태는 저장하거나 새로고침 후 재개하지 않습니다.

CVAT의 기본 2D 작업 화면과 `Ctrl+V` / `F` 키 설정에서 사용합니다. 객체 필터·특수 프레임 탐색·Track·다중 객체 복사는 지원하지 않습니다. 내부 준비 상태를 확인할 수 없는 CVAT 버전에서는 시작을 차단합니다. 회사에 설치된 CVAT에서의 실사용 검증은 별도로 필요합니다.

### 2.15.5 — 현재 Job 첫 라벨 자동 선택

- 첫 사용 또는 저장된 라벨이 없는 Job에서는 첫 번째 선택 가능한 라벨로 시작합니다. 현재 목록에 있는 수동 선택을 우선합니다.

### 2.15.4 — 이미지 가장자리 스켈레톤 그룹 누락 보완

- 중심점 또는 관절 하나 이상이 포함되면 폴리곤·박스를 함께 묶습니다.
- 이미 수동으로 같은 그룹에 묶은 대상은 유지합니다.

### 2.15.3 — 업데이트 후 구버전 그룹 검사 코드 잔류 수정

- 열린 CVAT 탭에서 이전 버전 코드가 최신 그룹 검사를 막던 문제를 수정했습니다.
- 버전별 요청 통로로 이전 핸들러와 분리하고 동일 버전 중복 실행을 방지합니다.

### 2.15.2 — 자기 교차 폴리곤 그룹 누락 수정

- 윤곽선이 교차하거나 꼭짓점이 중복된 폴리곤도 CVAT의 화면 채움 방식(nonzero)에 맞춰 그룹화합니다. 원본 좌표는 바꾸지 않습니다.
- 좌표를 읽을 수 없는 도형 하나 때문에 프레임 전체를 건너뛰던 동작을 수정했습니다. 해당 도형만 제외하고 나머지는 계속 검사합니다.
- 제외된 도형의 ID와 좌표 형식·회전·꼭짓점 수 등 구체적인 사유를 표시합니다.

### 2.15.1 — 폴리곤·박스·스켈레톤 그룹화 제한 완화

- 기존 그룹 번호와 관계없이 매칭된 폴리곤·박스·스켈레톤을 함께 새 그룹으로 묶습니다. 박스가 없으면 폴리곤과 스켈레톤만 묶습니다.
- 스켈레톤 중심이 도형 안에 있으면 연결합니다. 일부 관절이 밖으로 나오거나 같은 스켈레톤에 여러 도형이 겹쳐도 함께 그룹화합니다.
- 다른 프레임이나 비대상 객체가 기존 그룹에 포함되어 있어도 실행합니다. 매칭된 객체만 새 그룹으로 이동하며 비대상 객체는 유지합니다.
- 기존 그룹 추가 체크박스를 없앴습니다. 이미 같은 그룹인 대상은 중복 처리하지 않으며, 잠금·보호·Track 제외와 적용 전 변경 검사는 유지합니다.

### 2.15.0 — 폴리곤·스켈레톤 자동 그룹화

- 폴리곤만 있는 새 작업과 박스·폴리곤이 함께 있는 기존 작업을 지원합니다.
- 기존 박스를 삭제하지 않고 같은 스켈레톤을 포함한 폴리곤을 함께 묶습니다. 완전한 기존 박스 그룹에 새 폴리곤을 추가하는 옵션을 제공합니다.
- 오목한 윤곽·경계·겹침·기존 그룹 전체 소속을 검증하고 검사 결과에 객체 ID와 기존 그룹을 표시합니다.

### 2.14.1 — 이미지 미리 받기 연결 오류 수정

- 이미지 캐시가 다른 기능의 공유 연결 객체 없이도 현재 CVAT Job에 직접 연결하도록 수정했습니다.
- 이전 버전의 그룹 모듈이 페이지에 남아 공유 연결 객체 생성을 건너뛰던 경우를 복구합니다.
- `Cannot read properties of undefined (reading find)` 오류를 방지하며, 지원하지 않는 화면에서는 한국어 안내를 표시합니다.

### 2.14.0 — Job 이미지 미리 받기

- 화면 탭에서 현재 Job의 압축 이미지를 백그라운드로 받습니다. 진행률·캐시 사용량·재사용 횟수를 표시합니다.
- 중지 후에도 받은 이미지는 재사용하며 다시 시작하면 남은 부분을 받습니다. 캐시 비우기는 확장 캐시만 해제합니다.
- 기본 512 MB, 선택 256 MB / 1 GB. 한도 도달 시 중단하며 더 큰 Job 전체가 메모리에 들어간다고 보장하지 않습니다. 디코딩 메모리는 별도이며 주변 프레임 준비는 CVAT 기본 기능을 유지합니다.
- Job 변경·새로고침·확장 끄기 시 해제합니다. 일반 annotation Job만 지원하며 원본이 교체되면 캐시를 비우세요. 항목은 30분 뒤 만료됩니다.

### 2.13.0 — Job 전체 스켈레톤 location 일괄 변경

- 화면 탭에서 현재 Job의 스켈레톤 Shape를 tag 또는 sticker로 일괄 지정합니다. 실제 라벨별 속성 ID와 선택값을 읽습니다.
- 변경 대상·이미 같은 값·제외 사유를 확인하고 적용합니다. 좌표·그룹·다른 속성 및 관절 속성을 유지합니다.
- 잠금·보호 객체·삭제 프레임·Track·속성 미지원 대상을 제외합니다. 검사 후 변경 감지, 적용 후 결과 검증과 CVAT 기본 되돌리기를 지원합니다.

### 2.12.1 — 회전 화면 0° 복귀 잠김 수정

- 도구·그룹 선택 상태에서 일반 회전 버튼과 함께 0° 복귀까지 잠기던 문제를 수정했습니다.
- **도구 취소 후 0°**는 CVAT의 기본 취소 동작으로 진행 중인 도구를 종료하고 원래 방향으로 복구합니다. 완성 전 그리기는 취소되며 기존 객체는 유지됩니다.
- 저장·로딩·재생·드래그 중에는 복귀를 막고 이유를 회전 버튼 바로 아래에 표시합니다. 도구 취소가 실패하면 각도를 강제로 바꾸지 않습니다.

### 2.12.0 — 박스 안 스켈레톤 자동 그룹화

- 화면 탭에서 현재 프레임 또는 Job 전체의 박스·스켈레톤 포함 관계를 검사합니다.
- 모든 관절이 박스 안에 있는 스켈레톤만 박스별 그룹으로 묶습니다. 회전 박스 지원, 빈 박스 유지, 한 박스의 여러 스켈레톤은 같은 그룹으로 처리합니다.
- 겹치는 박스·기존 그룹·잠금·보호·Track을 제외하고 사유를 표시합니다. 적용 직전 재검사와 적용 후 그룹·모양 검증을 추가했습니다.
- CVAT 기본 그룹·이력을 사용하고 저장은 CVAT에서 합니다. 원본 좌표·라벨은 유지하며 새 권한은 없습니다.

### 2.11.1 — 회전 이미지에서 수평 스켈레톤 생성

- 이미지를 돌렸을 때 새 스켈레톤 생성 틀까지 기울던 문제를 수정했습니다. 생성 틀은 화면 수평·수직을 유지합니다.
- 두 모서리 클릭 또는 드래그로 완성한 관절을 CVAT의 실제 SVG 좌표 변환으로 원본 이미지 위치에 적용합니다. 0° 복귀 후에도 바코드와의 위치가 유지됩니다.
- Esc 취소·N 완료·확대·이동을 처리하고, 프레임 변경 또는 이미지 밖 관절이 있으면 생성을 취소합니다.
- 기존 객체, 붙여넣기·다시 그리기와 0° 생성은 CVAT 기본 동작을 유지합니다. 지원하지 않는 CVAT에서는 0° 복귀를 안내합니다.

### 2.11.0 — 라벨 숨김과 화면 정렬

- 라벨 오버레이에 Job별 전체 숨김·표시 버튼을 추가했습니다.
- 화면 탭에서 1도 단위 회전·각도 입력·0도 복귀를 지원합니다.
- 회전하지 않는 수평·수직 격자의 간격·선명도·색상을 조절할 수 있습니다.
- 스켈레톤 좌표 변환과 회전 상태의 확대·축소를 함께 처리하며, 마스크·AI 전환 시 0도로 복귀합니다.

### 2.10.0 — 회전 사각형·스켈레톤 단축키

- 두 키를 팝업에서 지정·변경·해제할 수 있습니다. 기존 키·라벨 단축키와 중복 지정을 막고 기존 설정은 유지합니다.

### 2.9.0 — 검수에서 특정 라벨 찾기

### 2.8.0 — 선택 라벨 스캔과 HTTP 범위 지정 오류 수정

- 프레임을 30개씩 표시하고 라벨별 프레임·객체 수를 안내합니다. 스캔 후 데이터 변경·만료를 확인합니다.
- 팝업과 오버레이에 동일하게 적용했습니다. 적용 전 확인과 기존 편집 제한을 유지합니다.

### 2.7.1 — Job 이동 후 연결 상태 복구

### 2.3.1 — 오류 알림과 내 기기 연결 상태

- 측정 중인 CVAT 화면 오른쪽 위에 서버 오류·요청 실패·로그인 및 권한 문제를 8초간 알립니다. 직접 닫을 수 있으며 같은 종류는 1분에 한 번만 표시합니다.
- 팝업의 **오류·연결 끊김 알림**을 꺼도 측정은 유지합니다. 알림 설정은 같은 Chrome 프로필에서 기억합니다.
- **내 기기 연결**은 Chrome의 온라인·오프라인 감지 결과를 표시합니다. 측정 중에는 팝업이 닫혀 있어도 연결 끊김을 알리고, 복구되면 끊김 알림을 지웁니다.
- Wi-Fi 신호 세기나 인터넷·CVAT 접속 성공을 보증하지 않습니다. 별도 프로그램 설치, 추가 점검 요청, 외부 전송은 없습니다.

### 2.3.0 — 내 CVAT 연결 상태

- **이 CVAT 서버에서 자동 측정**을 체크하면 설정을 기억하고 새로고침·Job 이동·브라우저 재시작 후 작업 화면에서 다시 측정합니다. 팝업은 닫아도 됩니다. 팝업의 측정 끄기는 현재 탭만 다음 새로고침/Job 이동까지 잠시 끄고, 체크 해제는 해당 서버의 자동 측정과 열려 있는 측정을 끕니다.

- 팝업 상단 **단축키 / 연결 상태**로 화면을 전환합니다. **연결 상태 → 측정 시작**으로 켜며 통계는 팝업 안에서 확인합니다. 연결 상태 오버레이는 표시하지 않습니다. 단축키 기능과 독립적으로 켜고 끕니다.
- 기존 CVAT API 요청만 관찰합니다. 추가 점검 요청·외부 전송·회사 이미지 수집은 없습니다.
- 일반 API / 이미지 / 저장 / AI를 구분하여 최근 5분(최대 300건) 중앙값과 오류 건수를 표시합니다. 상태 판단은 최근 1분 기준이며 캐시·취소 요청은 제외합니다.
- 서버 오류·네트워크 실패·요청 제한·인증 및 권한 문제를 구분합니다. 내 연결 상태이며 서버 자체의 건강이나 저장 성공을 보증하지 않습니다.
- `webRequest`와 사이트 접근은 선택 권한입니다. 상태 보기를 누르면 현재 CVAT 호스트만 허용을 요청합니다. 허용은 Chrome에 유지되지만 측정은 직접 켠 Job 탭의 같은 origin 요청에만 적용됩니다. Chrome 확장 관리에서 사이트 권한을 철회할 수 있습니다.
- 통계는 `storage.session`에 저장되어 서비스 워커 재시작 때 복구됩니다. 새로고침·다른 Job 이동·탭 종료·끄기에서 삭제됩니다. 브라우저 재시작 후에도 유지하는 작업 기록이 아닙니다.
- 개인 연결 상태만 표시합니다. 팀 대시보드나 다른 사용자와의 통계 공유는 제공하지 않습니다.
- 로컬 설치본은 확장을 새로고침한 뒤 사용하세요. GitHub 릴리스와 웹스토어 자동 제출 결과는 [Actions](https://github.com/r2gul4r/CVAT_shortcut/actions)에서 확인합니다. GitHub에 올라온 소스 버전과 웹스토어 심사·배포 버전은 다를 수 있습니다.

- CSS 확대, 상위 요소의 위치·배율 변화, 확대된 화면 영역, 브라우저 창 크기 변경, 저장된 화면 밖 좌표를 처리했습니다.
- 이미 열린 창도 화면 변화에 따라 다시 보정하도록 했습니다.
- 창이 일부만 보여도 정상 표시로 판단하던 상태 검사를 수정했습니다.
- 별도 Chrome 환경과 모의 CVAT 화면을 사용한 전체 검사 **443개**를 통과했습니다.

### 2.1.2 — 오버레이 복구와 전체화면 표시 수정

- 팝업에 **라벨 선택창 복구**를 제공해 위치·크기·투명도·최소화 상태를 기본값으로 되돌리도록 했습니다.
- 숨김 스타일도 초기화하되, 선택 라벨과 단축키 설정은 유지하도록 했습니다.
- CVAT 요소 전체화면에서는 오버레이를 전체화면 요소 안으로 옮기고, 해제하면 문서 루트로 되돌리도록 했습니다.
- 복구 결과의 실제 표시 상태를 확인하고, 구버전 코드가 남은 탭에는 RELOAD 안내를 표시하도록 했습니다.
- 이후 사용 중 창이 반쯤 화면 밖에 남는 문제가 보고되어 2.1.3에서 위치 보정을 추가로 수정했습니다.

### 2.1.1 — N 라벨 연동 실패 수정

- CVAT 기본 작업 공간의 이름을 `standard`로 비교하던 오류를 실제 값인 **`Standard`**로 수정했습니다.
- 기본 작업 공간에서도 N 시작이 차단되던 조건을 바로잡고, 같은 잘못된 값을 사용하던 테스트도 수정했습니다.
- 연동 실패 시 STORE·WORKSPACE·BRIDGE 등의 고정된 확인 코드를 표시하도록 했습니다.
- 오류 안내에 작업 ID·이미지 이름·라벨 값 등 작업 데이터를 포함하지 않도록 했습니다.

### 2.1.0 — N으로 이전 도구를 불러올 때 선택 라벨 적용

- 오버레이·팝업·라벨 단축키로 선택한 라벨을 **CVAT 기본 N 이전 도구 호출**에도 적용했습니다.
- 새 객체를 시작하기 직전에 다음 라벨만 바꾸고, 이전 도구·객체 종류·AI 모델·그리기 옵션은 보존하도록 했습니다.
- 그리기·편집 중에는 현재 객체의 라벨을 유지하고 CVAT의 기존 N 완료·종료 처리로 넘기도록 했습니다.
- CVAT 상태와 선택 라벨의 호환성을 확인할 수 없는 경우 시작을 중단하고 안내하도록 했습니다.
- 이 연결은 CVAT 내부 상태 구조를 이용하므로 CVAT 버전에 따른 호환성 확인이 필요합니다.

### 2.0.0 — 이동·크기 조절 가능한 라벨 오버레이

- 확장 팝업을 계속 열지 않아도 작업 화면에서 라벨을 선택할 수 있는 **라벨 선택 오버레이**를 만들었습니다.
- 제목을 드래그해 이동하고, 색상칩과 이름을 눌러 다음 객체의 라벨을 선택하도록 했습니다. 지정한 라벨 단축키도 함께 표시했습니다.
- 하단에 **투명도 0~70%** 조절을 추가하고, 위치·크기·투명도·최소화 상태를 저장하도록 했습니다.
- 예시 라벨 6개를 사용하는 데모를 만들고, 팝업에 **라벨 선택창 사용** 켜기·끄기를 추가했습니다. 실제 확장은 해당 작업의 전체 라벨을 표시합니다.
- 창을 줄이면 목록에 스크롤이 생기고, 넓히면 2열·3열 등으로 자동 배치되는 반응형 목록을 구현했습니다.
- 창의 네 변과 네 모서리 어디서든 크기를 조절하도록 했습니다.
- **×는 완전히 끄기**, **−는 작은 버튼으로 최소화**로 구분하고, 최소화된 버튼도 드래그로 움직일 수 있도록 수정했습니다.
- 오버레이 조작이 CVAT 캔버스 입력으로 전달되는 문제와 슬라이더·포커스·보조키 해제 처리를 보완했습니다.

### 1.9.0 — 라벨 선택 단축키와 우선 처리

- 확장프로그램에서 사용하는 **다음 객체의 라벨**을 단축키로 선택할 수 있도록 했습니다.
- 라벨별 단축키 지정·변경·해제를 추가하고, 선택한 라벨을 다음 AI·새 마스크 시작에 적용했습니다.
- 등록한 확장 단축키를 먼저 처리하고, 키 반복·해제도 함께 관리하도록 했습니다.
- 라벨을 바꾼 직후 도구를 실행해도 새 선택을 사용할 수 있도록 저장 전 선택값을 즉시 반영했습니다.
- 기존 객체나 현재 그리는 객체의 라벨을 바꾸는 CVAT 자체 기능과는 별도로 동작하도록 했습니다.

### 1.8.0 — Space를 누른 채 화면 이동

- 브러쉬를 사용하는 중 **Space + 왼쪽 드래그**로 화면을 이동하는 기능을 추가했습니다.
- CVAT의 기본 가운데 버튼 이동 동작을 이용해, 브러쉬를 해제하거나 다시 선택하지 않고 이동하도록 했습니다.
- Space와 마우스를 놓으면 이어서 그릴 수 있도록 하고, 팝업에서 기능을 켜고 끌 수 있게 했습니다.
- 키·마우스를 놓는 순서, 창 포커스 상실, 이미 진행 중인 스트로크, 작업 화면 변경에 따른 입력 정리를 보완했습니다.
- 가이드에 Space 이동 사용법과 관련 팝업 화면을 추가했습니다.

### 1.7.3 — 실제 확장 화면을 넣은 적용 가이드

- 가이드를 **업데이트 → 확장 켜기 → 라벨 선택 → 단축키 지정 → 작업 중 사용** 순서로 쉽게 다시 작성했습니다.
- 실제 확장 코드를 예시 라벨·모의 API와 함께 실행한 로컬 시연 화면을 캡처해 이미지 5장을 넣었습니다.
- ZIP 설치와 웹스토어 업데이트 방법을 구분하고, V·B는 직접 지정하는 예시 키임을 설명했습니다.
- 이미지를 확장에 포함해 오프라인에서도 가이드를 볼 수 있도록 했습니다.
- 도구 기능 코드는 1.7.2와 동일하게 유지했습니다.

### 1.7.2 — 도구 창만 열리고 실행되지 않는 오류 수정

- AI와 새 마스크 모두 메뉴만 열리고 Interact·Shape까지 진행되지 않는 현상을 조사했습니다.
- CVAT가 메뉴를 열면서 보내는 버튼 없는 마우스 이벤트를 실제 왼쪽 버튼 누름으로 잘못 기록하던 처리를 수정했습니다.
- 버튼 없는 알림은 무시하고, 실제 마우스 버튼을 누른 상태만 추적하도록 했습니다.
- AI·마스크 메뉴의 같은 이벤트를 재현해 실행이 중단되는 문제를 검사했습니다.

### 1.7.1 — 색상과 이름을 하나의 선택 목록으로 통합

- 라벨 드롭다운과 별도 색상 선택 UI를 하나의 목록으로 합쳤습니다.
- 각 행에 **색상칩 + 라벨 이름**을 함께 표시하고, 선택한 행을 강조했습니다.
- 선택 즉시 저장, 목록 새로고침, 직접 입력 대체 경로는 유지했습니다.

### 1.7.0 — 다른 도구에서 단축키로 바로 전환

- AI·새 마스크 단축키 실행 앞에 **Esc**를 전달하도록 했습니다.
- 활성 도구가 해제된 것을 확인한 뒤 메뉴 열기 → 라벨 선택 → Interact 또는 Shape 실행으로 이어지도록 했습니다.
- 사용자가 직접 Esc를 누르지 않아도 다른 도구로 전환할 수 있게 했습니다.
- 키를 계속 누르고 있거나 전환이 이미 진행 중이면 중복 실행하지 않도록 했습니다.
- 이 동작은 현재 작업을 완료하는 기능이 아니라 Esc에 따른 취소·전환입니다. 진행 중인 그리기가 취소될 수 있습니다.

### 1.6.1 — 라벨 대표색 표시

- CVAT 라벨의 대표색을 읽어 색상칩으로 표시했습니다.
- 선택한 라벨의 색상 표시와 **대표색으로 선택** 목록을 추가했습니다.
- 색상 항목을 눌러도 같은 라벨 선택·저장 절차를 사용하도록 했습니다.
- 색상을 읽지 못한 경우 임의의 색을 만들지 않고, Labels 탭을 열어 새로고침하도록 안내했습니다.

### 1.6.0 — 이 탭의 라벨 선택

- 기본 라벨 이름을 매번 직접 입력하는 불편을 줄이기 위해 **이 탭의 라벨 선택** 기능을 추가했습니다.
- 현재 작업에 등록된 전체 클래스 목록을 읽고, 아직 사용하지 않은 클래스도 표시하도록 했습니다.
- Overview의 합계 행은 제외하고, 목록에서 라벨을 선택하면 다음 객체의 기본 라벨로 저장하도록 했습니다.
- 목록 새로고침, 이름 중복 확인, 목록을 읽지 못했을 때의 직접 입력 경로를 마련했습니다.
- 작업별 라벨 목록은 저장하지 않고, 선택한 이름만 기존 설정에 저장하도록 했습니다.

### 1.5.0 — 한글 UI와 내장 가이드

- CVAT의 기본 휠 버튼 드래그 이동과 문제 해결 방법을 안내했습니다.
- 기존 단축키 설정과 권한을 유지했습니다. 한글화 대상은 확장프로그램 UI입니다.

### 1.4.1 — 단축키 이벤트 충돌 보완

- 확장이 처리하기로 한 키를 CVAT의 일반 키 처리보다 먼저 받을 수 있도록 이벤트 처리 위치를 변경했습니다.
- 키를 길게 누를 때의 반복 입력과 키 해제까지 처리해, 확장 실행 후 같은 입력이 CVAT에 다시 전달되는 경우를 줄였습니다.
- Ctrl·Shift·Alt·Cmd 해제는 전달해 보조키가 눌린 상태로 남지 않도록 했습니다.
- 입력창·한글 조합·지원하지 않는 화면에서의 예외 처리와 수동 확인 가이드를 보완했습니다.
- 별도로 준비했던 **0.1.1 스토어용 번호는 취소**하고 개발판과 같은 1.4.1 이름·버전을 사용하기로 했습니다. `releases/0.1.1/`은 취소된 준비 기록입니다.

### 1.4.0 — Mac 키 표시와 배포 준비

- Mac에서는 Alt를 **Option**, Meta를 **Cmd**로 표시하고 Ctrl과 Cmd를 구분하도록 했습니다.
- 브라우저·운영체제가 사용하는 키 조합을 지정하면 충돌 가능성을 안내하도록 했습니다.
- Cmd + 휠 등 기본 브라우저 입력을 유지하고, Mac 키 입력을 모의한 검사를 추가했습니다.
- 확장 아이콘과 웹스토어 업로드용 ZIP, 설치·권한·개인정보 처리 안내 자료를 준비했습니다.

### 1.3.1 — 브러쉬 휠 조절 개선

- 브러쉬 크기 조절을 **Alt + 휠 / Shift + 휠**로 변경했습니다.
- Ctrl + 휠과 터치패드 핀치는 기존 확대·축소 동작으로 남겼습니다. 이전에 저장된 Ctrl + 휠 설정은 Alt로 이전했습니다.
- 조절 폭을 한 단계에 **5px → 1px**로 줄여 미세하게 조절할 수 있도록 했습니다.
- 작은 터치패드 입력을 누적하고, Shift + 휠이 가로 방향 입력으로 들어오는 경우도 처리했습니다.

### 1.3.0 — 새 객체의 기본 라벨 지정

- 팝업에 새 객체에 사용할 기본 라벨 이름을 직접 입력하고 저장하는 기능을 추가했습니다.
- AI·새 마스크 도구를 시작하기 전에 지정한 라벨을 선택하고, 선택 결과를 확인하도록 했습니다.
- 정확히 일치하는 라벨이 없거나 이름이 중복되면 임의의 다른 라벨로 시작하지 않도록 했습니다.
- AI 모델과 다른 도구 옵션은 유지하고, 기존 객체의 라벨은 변경하지 않도록 했습니다.

### 1.2.0 — 메뉴 열기에서 실제 도구 시작까지

- AI 단축키가 메뉴를 연 뒤 **Interact**까지, 새 마스크 단축키가 메뉴를 연 뒤 **Shape**까지 실행하도록 확장했습니다.
- 메뉴가 준비될 때까지 기다린 뒤 실행하고, 연속 입력으로 중복 실행되지 않도록 처리했습니다.
- 활성 마스크 캔버스에서 수정키와 마우스 휠로 브러쉬·지우개 크기를 조절하는 기능을 추가했습니다.
- 이때는 Alt 또는 Ctrl + 휠을 지원했고, 한 단계에 5px씩 조절했습니다. 이후 1.3.1에서 조합과 조절 폭을 변경했습니다.

## 현재 확인 사항

- **N 중복 지정 처리: 보류.** 확장 AI·새 마스크 단축키를 N으로 지정하면 CVAT의 N 완료 동작과 충돌할 수 있습니다. 시작·완료를 상태별로 구분하는 방안은 계획만 검토했으며 현재 코드에 적용하지 않았습니다.
- **확장 단축키 우선 처리의 범위:** Chrome·운영체제가 먼저 사용하는 키까지 우선권을 보장하지는 않습니다. 입력창·한글 조합·대화상자에서는 별도 예외 처리를 적용합니다.
- **검증 범위:** 예시 화면과 모의 API, 별도 Chrome 실행 환경 기준입니다. Mac 검사는 Windows에서 입력·플랫폼 정보를 모의한 것이며, 실제 Mac 기기나 모든 CVAT 설치본의 동작을 보증하는 검사는 아닙니다.
- **이전 자료:** `store/`와 `INSTALLATION-STATUS.md`에는 초기 배포 준비 기록이 남아 있습니다. 현재 설치와 패키징은 이 README 상단의 현재 버전 안내를 사용하세요.
