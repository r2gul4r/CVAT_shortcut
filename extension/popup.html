단축키 · 라벨 사용 안내

AI·새 마스크·폴리곤과 N으로 새 객체를 시작할 때 선택한 라벨을 사용합니다. 기존 객체와 현재 그리는 객체의 라벨은 바뀌지 않습니다.

N은 이전 도구와 설정을 불러옵니다. N을 확장 단축키로 지정하면 해당 확장 기능이 우선합니다.

라벨이나 색상이 없으면 CVAT의 Labels 또는 Overview를 열고 목록을 새로고침하세요. 선택창이 보이지 않으면 작업창 복구를 누르세요.

설정은 같은 Chrome 프로필의 탭들이 공유합니다. 페이지를 새로고침하면 확장을 다시 켜주세요. 선택창만 꺼도 단축키는 계속 작동합니다.

지정한 확장 단축키는 CVAT보다 우선합니다. 입력칸·IME·대화상자에서는 기존 입력을 유지합니다.

팝업을 닫아도 계속 측정

처음 켤 때 현재 CVAT 사이트의 접근 권한을 허용하세요.

새로고침·Job 이동·Chrome 재시작 후 작업 화면에서 다시 시작합니다. 체크를 해제하면 이 서버의 측정을 끕니다.

측정 중인 CVAT 화면 오른쪽 위에 8초간 표시합니다. 같은 종류는 1분에 한 번만 알리며 직접 닫을 수 있습니다.

이 탭의 알림을 연결하지 못했습니다. 측정은 계속됩니다. 작업을 저장한 뒤 페이지를 새로고침하고 다시 켜주세요.

열려 있는 동안 2초마다 갱신합니다. 추가 점검 요청이나 외부 전송은 없습니다. 응답 시간에는 서버·네트워크·다운로드 시간이 포함되며 저장 성공을 보장하지 않습니다.

누락 검사 · 라벨 찾기

확인할 라벨을 고르세요. ‘누락 프레임 검사’는 라벨이 없는 프레임을, ‘선택 라벨 찾기’는 라벨이 있는 프레임을 보여줍니다.

라벨 확인 전

선택은 이 서버의 Job별로 기억합니다.

먼저 CVAT에서 작업을 저장하세요. 미저장 수정은 검사에 포함되지 않습니다.

여러 라벨을 찾으면 선택한 라벨 중 하나라도 있는 프레임을 모아 보여줍니다.

CVAT Job 탭에서 열어주세요.

이전 검사 결과입니다. 수정·저장 후 다시 검사하세요. 번호는 CVAT 화면과 같습니다.

라벨누락 수누락 프레임
검사 기준 · 데이터 보관

저장된 Shape와 Track을 검사합니다. Track의 Outside 구간과 삭제 프레임은 제외하고, 화면에서 숨기거나 필터로 가린 객체도 포함합니다. Tag는 그린 객체로 세지 않습니다. Skeleton Track은 지원하지 않으며 검사 오류로 안내합니다.

라벨이 있으면 통과합니다. 객체 수·모양·손잡이 등 세부 누락은 판단하지 않습니다. 그림이나 라벨링을 자동으로 변경하거나 저장하지 않습니다.

검사를 누를 때 현재 CVAT 서버에서 데이터를 읽습니다. 이미지 조회와 외부 전송은 없습니다. 선택한 라벨과 마지막 결과(이름·누락 또는 찾은 프레임·시각)는 이 Chrome 프로필에 보관하며, 좌표·마스크·속성은 보관하지 않습니다.

라벨 일괄 편집

현재 Job 확인 전

① 편집할 라벨을 고르고 스캔하세요. 해당 라벨이 있는 프레임을 새로 찾습니다.

먼저 CVAT 작업을 저장하세요. 숨김·필터로 가린 객체도 포함합니다.

선택한 라벨 중 하나라도 있는 프레임입니다. 번호는 CVAT 화면과 같습니다.

② 범위와 작업 선택

쉼표로 여러 번호·구간을 함께 지정합니다. 해당 범위에 있는 선택 라벨의 객체만 편집합니다.

클래스 목록과 객체 모양은 유지합니다. Track이 포함되면 검색된 전체를 선택해야 합니다.

③ 적용 전 확인

적용 후 CVAT에서 확인하고 저장하세요. CVAT 자동 저장을 켰다면 해당 설정에 따라 저장될 수 있습니다. 라벨 변경 시 속성은 새 라벨 기준으로 바뀝니다.

편집 범위와 제한

마스크·폴리곤 등 Shape를 지원합니다. Track의 프레임 목록은 Outside 구간을 제외하지만 편집은 검색된 전체에서 Track 단위로 적용합니다. Tag·Skeleton은 대상이 아니며, 잠금·보호 객체 또는 확인할 수 없는 객체가 포함되면 실행하지 않습니다.

스캔은 현재 저장된 객체 정보 기준입니다. 삭제된 프레임에 객체 정보가 남아 있으면 목록에 포함될 수 있으며, 편집 연결을 확인하지 못하면 중단합니다. 스캔 후 데이터가 바뀌거나 5분이 지나면 다시 스캔하세요.

CVAT의 현재 작업에 반영하며 확장이 저장 버튼을 누르지는 않습니다. 되돌리기는 CVAT의 실행 취소를 사용합니다. 여러 객체는 여러 단계로 기록될 수 있습니다.
