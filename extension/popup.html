단축키 · 라벨 사용 안내

AI·새 마스크·폴리곤과 N으로 새 객체를 시작할 때 선택한 라벨을 사용합니다. 기존 객체와 현재 그리는 객체의 라벨은 바뀌지 않습니다.

N은 이전 도구와 설정을 불러옵니다. N을 확장 단축키로 지정하면 해당 확장 기능이 우선합니다.

라벨이나 색상이 없으면 CVAT의 Labels 또는 Overview를 열고 목록을 새로고침하세요. 선택창이 보이지 않으면 선택창 복구를 누르세요.

설정은 같은 Chrome 프로필의 탭들이 공유합니다. 페이지를 새로고침하면 확장을 다시 켜주세요. 선택창만 꺼도 단축키는 계속 작동합니다.

지정한 확장 단축키는 CVAT보다 우선합니다. 입력칸·IME·대화상자에서는 기존 입력을 유지합니다.

팝업을 닫아도 계속 측정

처음 켤 때 현재 CVAT 사이트의 접근 권한을 허용하세요.

새로고침·Job 이동·Chrome 재시작 후 작업 화면에서 다시 시작합니다. 체크를 해제하면 이 서버의 측정을 끕니다.

측정 중인 CVAT 화면 오른쪽 위에 8초간 표시합니다. 같은 종류는 1분에 한 번만 알리며 직접 닫을 수 있습니다.

이 탭의 알림을 연결하지 못했습니다. 측정은 계속됩니다. 작업을 저장한 뒤 페이지를 새로고침하고 다시 켜주세요.

열려 있는 동안 2초마다 갱신합니다. 추가 점검 요청이나 외부 전송은 없습니다. 응답 시간에는 서버·네트워크·다운로드 시간이 포함되며 저장 성공을 보장하지 않습니다.
