이 탭의 라벨 선택

AI·새 마스크 단축키와 N으로 새 객체를 시작할 때 사용할 라벨을 선택하세요. 선택하면 자동 저장됩니다.

각 라벨의 ‘키 지정’으로 빠르게 바꿀 수 있습니다. 기존 객체와 현재 그리는 객체는 유지하고 다음 객체부터 적용됩니다. 같은 이름의 라벨이 있는 다른 작업에서도 사용할 수 있습니다.

N은 이전 도구와 설정을 유지하며 선택한 라벨로 다시 시작합니다. 그리는 중 N의 완료·종료 동작은 그대로입니다. Shift+N 다시 그리기도 유지됩니다.

색상이 없으면 CVAT 오른쪽 Labels 탭을 열고 목록을 새로고침하세요.

직접 입력

목록을 읽지 못할 때 사용하세요. 복사한 이름을 붙여넣을 수도 있습니다.

AI 도구

Esc로 현재 도구를 취소한 뒤 기본 라벨로 Interact를 실행합니다.

미지정

스페이스로 화면 이동

스페이스를 누른 채 이미지를 왼쪽 버튼으로 드래그하세요. 브러쉬를 켜 둔 상태로 화면만 이동합니다. 버튼과 스페이스를 놓은 뒤 다시 그리세요.

Space가 도구 또는 라벨 단축키로 지정되어 있어 해당 기능을 우선합니다. 지정된 키를 변경하거나 해제하면 화면 이동을 사용할 수 있습니다.

선을 긋는 중에는 먼저 마우스 버튼을 놓으세요. CVAT의 기존 Space 기능을 쓰려면 이 옵션을 끄세요.

브러쉬 크기

마스크를 그리거나 편집할 때 캔버스 위에서 사용합니다. 휠을 위로 돌리면 커지고 아래로 돌리면 작아집니다. 조절 단위는 1px, 범위는 1–500px입니다. 핀치와 Ctrl/Cmd + 휠은 기존 동작을 유지합니다.

새 마스크 (브러쉬)

Esc로 현재 도구를 취소한 뒤 기본 라벨로 Shape를 실행합니다.

미지정

이 탭에서 사용 중에는 지정한 확장 단축키가 CVAT보다 우선합니다. 도구가 준비되지 않아도 같은 키의 CVAT 기능을 실행하지 않습니다. 글자 입력 중·IME·대화상자에서는 기존 입력을 유지하며, Chrome·운영체제 단축키는 우선할 수 있습니다.

도구 단축키는 진행 중인 그리기·편집을 Esc처럼 취소할 수 있습니다. 라벨 단축키는 도구를 취소하지 않습니다. 설정은 이 Chrome 프로필의 탭들이 공유합니다. 새로고침하거나 새 탭을 열면 다시 사용 버튼을 눌러주세요.
