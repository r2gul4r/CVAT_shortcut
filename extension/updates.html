업데이트 내역

설치한 버전까지의 변경 내용을 최신순으로 볼 수 있습니다.

사용 가이드 GitHub에서 최신 배포 확인 ↗

2.9.0 · 검수에서 특정 라벨이 있는 프레임 찾기

  • 검수 탭에 선택 라벨 찾기를 추가했습니다. person 등 원하는 라벨을 체크하고 실행하면 그 라벨이 있는 프레임을 나열합니다.
  • 찾은 프레임 번호 클릭, 이전·다음 결과 이동, 라벨별 필터와 30개씩 목록 보기를 지원합니다. 여러 라벨은 하나라도 있는 프레임을 중복 없이 모아 보여줍니다.
  • 검색 결과 복사·CSV 저장, Job별 마지막 결과 보관과 팝업·오버레이 공유를 지원합니다. 기존 누락 검사는 별도 버튼으로 계속 사용할 수 있습니다.
  • 현재 Job에 저장된 Shape·Track을 조회하며 삭제 프레임과 Outside 구간을 제외합니다. 새 권한이나 이미지 조회, 라벨링 변경은 추가하지 않습니다.

2.8.0 · 선택 라벨 스캔 편집과 HTTP 범위 지정 오류 수정

  • HTTP로 접속하는 사내 CVAT에서 범위 지정 후 crypto.randomUUID is not a function 오류가 발생하던 문제를 수정했습니다.
  • 검수의 삭제·라벨 변경에서 편집할 라벨을 고르고 선택 라벨 스캔을 누르면, 해당 라벨이 있는 프레임과 객체 수를 새로 보여줍니다. 누락 검수 결과를 편집으로 가져오는 버튼은 제거했습니다.
  • 스캔한 프레임을 30개씩 확인하고 번호·구간 또는 검색된 전체를 선택합니다. 대상 확인에서 라벨·프레임·객체 수를 검토하고 체크한 뒤 삭제하거나 다른 라벨로 변경합니다.
  • 선택 라벨 변경, 스캔 후 데이터 변경 또는 5분 만료 시 다시 스캔하도록 처리했습니다. 편집 전 저장 확인과 적용 후 결과 확인을 유지합니다.
  • 팝업과 작업 오버레이에 같은 흐름을 적용했습니다. Track은 검색된 전체에서만 편집하며 Tag·Skeleton·잠금·보호 객체의 기존 제한을 유지합니다.

2.7.1 · Job 이동 후 오버레이 연결 상태 복구

  • 오버레이를 켠 채 다른 Job으로 이동하면 연결 상태 조회가 실패하고, 닫았다 다시 열어도 복구되지 않던 문제를 수정했습니다.
  • CVAT가 페이지를 새로 열지 않고 Job을 전환할 때 남는 이전 주소 대신, 현재 열린 페이지와 Job을 확인하도록 연결 검증을 바꿨습니다. 다른 페이지·프레임·Job에서 온 잘못된 요청은 계속 차단합니다.
  • Job 이동 후 수동 측정 시작, 자동 측정, 연결 끊김·복구 알림을 다시 사용할 수 있습니다. 작업 목록을 거쳐 다른 Job으로 들어가는 경우도 처리하며 이전 Job 통계는 섞지 않습니다.
  • 같은 연결을 사용하는 검수·삭제·라벨 변경 동작을 회귀 검사했습니다. 새 권한이나 서버 점검 요청은 추가하지 않습니다.

2.7.0 · 검수에서 프레임 지정 삭제·라벨 변경

  • 검수 탭에 누락 검수 / 삭제·라벨 변경 화면을 추가했습니다. 팝업과 작업 오버레이에서 같은 편집 기능을 사용할 수 있습니다.
  • 편집할 라벨을 고르고 3, 7, 20~40처럼 번호·구간을 함께 입력하거나 현재 Job 전체를 선택해 객체를 삭제하거나 다른 라벨로 변경합니다. 클래스 목록은 유지됩니다.
  • 누락 검수 결과의 현재 필터에 해당하는 프레임을 편집 화면으로 가져올 수 있습니다. 편집 대상 라벨은 별도로 선택합니다.
  • 대상 라벨·프레임·객체 수를 확인하고 체크한 뒤에만 적용합니다. 확인 후 데이터가 바뀌거나 5분이 지나면 다시 확인해야 합니다. 적용 후 결과도 검사하며 예상과 다르면 완료로 표시하지 않습니다.
  • 먼저 CVAT 작업을 저장한 뒤 사용하세요. CVAT의 기존 객체 편집 기능으로 반영하며 결과 확인 후 CVAT에서 저장합니다. 확장이 저장을 누르지는 않지만 CVAT 자동 저장 설정은 계속 적용됩니다.
  • Shape는 번호·구간·전체를 지원합니다. Track은 구간 밖 연결을 보호하기 위해 현재 Job 전체에서만 지원하며 Tag·Skeleton·잠금 객체는 편집하지 않습니다. 실제 설치된 CVAT 버전의 내부 연결이 필요합니다.

2.6.1 · 확장 업데이트 후 오버레이 연결 오류 수정

  • 확장을 업데이트하거나 다시 로드한 뒤 기존 CVAT 탭의 오버레이를 조작할 때 발생하던 Extension context invalidated 오류를 수정했습니다.
  • 끊어진 확장 연결을 감지하면 이전 오버레이와 화면 갱신을 종료하고, 작업을 저장한 뒤 CVAT 페이지를 새로고침하도록 안내합니다. 페이지를 자동으로 새로고침하지 않습니다.

2.6.0 · 라벨·검수·연결 상태 통합 오버레이

  • 기존 라벨 선택창의 틀을 유지하고 라벨 선택·검수·연결 상태 탭을 추가했습니다. 작업 화면에서 창의 내용만 바꿔 사용할 수 있습니다.
  • 이동, 모든 가장자리 크기 조절, 투명도, 최소화와 완전히 닫기를 세 화면에서 함께 사용합니다. 창이 작으면 내용이 스크롤되고 넓으면 필수 라벨 목록도 여러 열로 배치됩니다.
  • 오버레이에서 필수 라벨 선택·검사·누락 프레임 이동·결과 복사·CSV 저장을 지원합니다. 팝업과 Job별 선택 및 마지막 결과를 공유합니다.
  • 오버레이에서 연결 상태 통계·측정 켜기/끄기·자동 측정·오류 알림을 조작합니다. 최초 사이트 권한은 확장 팝업에서 허용하며, 오버레이를 닫아도 켜진 측정은 계속됩니다.
  • 팝업의 검수·연결 상태 화면에 해당 오버레이를 바로 여는 버튼을 추가했습니다. 다른 Job으로 이동하면 이전 Job의 검수 화면을 비우고 새 Job 기준으로 표시합니다.

2.5.1 · 검수 조회 HTTP 406 오류 수정

  • 필수 라벨 검수에서 CVAT 전용 JSON 응답 형식을 허용하도록 수정했습니다. 라벨 목록이나 전체 프레임 조회 시 발생하던 HTTP 406 오류를 해결합니다.
  • 일반 JSON 응답도 함께 허용하며 추가 조회나 재시도 없이 기존 요청으로 처리합니다.

2.5.0 · 필수 라벨 누락 검수

  • 팝업에 검수 탭을 추가했습니다. 현재 Job의 라벨과 대표색을 보고 모든 프레임에 필요한 라벨을 여러 개 선택할 수 있습니다. 선택은 서버·Job별로 저장합니다.
  • CVAT에서 저장한 뒤 전체 프레임을 검사하면 라벨별 누락 프레임과 중복을 제외한 누락 프레임 수를 보여줍니다. Shape와 Track의 표시 구간을 반영하고 삭제 프레임을 제외합니다.
  • 누락 프레임 번호 클릭, 이전·다음 누락 이동, 라벨별 필터와 목록 페이지 이동을 제공합니다. CVAT의 프레임 번호를 그대로 사용합니다. 그리기·저장·재생 중에는 이동을 차단합니다.
  • 결과 복사와 CSV 저장을 지원하며 마지막 검사 결과는 팝업을 닫아도 보관합니다. 수정·저장 후 다시 검사하면 누락 목록이 갱신됩니다.
  • 사용자가 검수 화면을 열거나 검사를 누르면 현재 CVAT 서버의 Job·라벨·프레임·저장된 주석을 조회합니다. 이미지를 조회하거나 데이터를 외부로 전송하지 않으며 기존 라벨링을 변경·저장하지 않습니다. API 오류나 지원하지 않는 형식은 검사 실패로 안내합니다.
  • 객체의 모양·세부 영역과 Skeleton Track 검수는 이번 버전에 포함하지 않습니다.

2.4.0 · 붙여넣기 반복 매크로

  • 객체 하나를 직접 그리고 복사한 뒤, 처음 붙여넣을 프레임에서 Ctrl+V → 왼클릭 확정 → F를 반복할 수 있습니다. 팝업의 반복 시작 버튼이나 직접 지정한 단축키로 시작합니다.
  • 반복 횟수 제한 없이 실행하며 Esc 또는 실행 단축키로 중지합니다. 마우스 이동·클릭·다른 키 입력·작업 화면 이탈·마지막 프레임에서도 중지합니다.
  • 붙여넣기 미리보기 준비, 객체 하나의 추가, 다음 프레임 로딩을 순서대로 확인합니다. 확인 실패 시 같은 프레임에 재시도하지 않고 중지합니다.
  • 복사한 객체의 라벨과 CVAT의 붙여넣기 위치를 사용합니다. 확장 라벨 선택으로 변경하지 않으며 저장은 직접 합니다. 별도 클립보드 권한이나 외부 서버는 필요하지 않습니다.
  • 매크로 화면 알림은 시작·중지·오류 때만 표시합니다. 반복 중 붙여넣은 개수 안내는 화면에 띄우지 않습니다.

2.3.1 · 오류 알림과 내 기기 연결 상태

  • 측정 중 서버 오류·요청 실패·로그인 및 권한 문제를 감지하면 CVAT 화면 오른쪽 위에 알립니다. 8초 뒤 자동으로 사라지며 직접 닫을 수 있습니다.
  • 같은 종류의 알림은 1분에 한 번만 표시합니다. 팝업에서 오류·연결 끊김 알림을 꺼도 요청 통계는 계속 측정합니다.
  • 내 기기 연결에 Chrome이 감지한 온라인·오프라인 상태를 표시합니다. 팝업이 닫혀 있어도 측정 중인 페이지에서 연결 끊김을 알리고, 복구되면 끊김 알림을 지웁니다.
  • 추가 점검 요청·외부 전송·별도 프로그램 설치는 없습니다. Wi-Fi 신호 세기나 장애 원인을 확정하는 기능은 아닙니다.

2.3.0 · 내 CVAT 연결 상태

  • 팝업을 단축키 / 연결 상태 화면으로 나눴습니다. 연결 상태 오버레이 없이 팝업 안에서 요청 건수·종류별 중앙값·오류를 확인합니다. 라벨 선택 오버레이는 기존대로 사용할 수 있습니다.
  • F12 없이 기존 CVAT API 요청을 관찰합니다. 팝업을 닫아도 계속 집계하며, 다시 열면 최신 통계를 표시합니다. 연결 상태 화면은 2초마다 갱신합니다.
  • 이 CVAT 서버에서 자동 측정을 켜면 새로고침·다른 Job 이동·브라우저 재시작 후 작업 화면에서 다시 시작합니다. 설정은 서버별로 기억합니다.
  • 응답 정상·지연·오류·로그인 및 권한 문제·최근 측정 없음을 구분합니다. 추가 점검 요청이나 외부 전송 없이 제한된 통계를 브라우저 세션에만 보관합니다.
  • 요청 감시와 현재 CVAT 호스트 접근을 선택 권한으로 요청합니다. 거절해도 기존 단축키는 사용할 수 있습니다. 캐시와 사용자 취소는 집계에서 제외합니다.

2.2.1 · 업데이트 내역과 자동 배포 준비

  • 팝업에 업데이트 내역 버튼을 추가했습니다. 설치한 버전까지의 변경 내용을 확장 안에서 확인할 수 있습니다.
  • GitHub의 최신 릴리스로 이동하는 링크를 추가했습니다.
  • 패치노트 원본을 한 곳에서 관리해 확장 내부 화면과 GitHub 릴리스에 함께 반영합니다.
  • 버전이 올라간 main 푸시에서 검사, ZIP 생성, GitHub 릴리스 게시를 자동 실행합니다. 웹스토어 인증을 연결하면 심사 제출까지 이어집니다.
  • 팝업의 폭을 400px로 고정해 좁게 열리며 글자가 세로로 끊기는 문제를 수정했습니다.

2.2.0 · 폴리곤 단축키와 라벨 연동

  • 팝업에 새 폴리곤 단축키 지정·변경·해제를 추가했습니다.
  • 도구 단축키를 상단에 모으고 라벨 선택·키 지정 행을 정렬했습니다. 화면 이동·브러쉬 설정과 상세 안내는 접어 볼 수 있습니다. 화면 비교.
  • 오버레이 또는 라벨 단축키로 고른 다음 객체 라벨을 폴리곤에도 적용합니다.
  • 실행 시 기존 도구를 Esc로 취소하고 Number of points 공란, Simplify OFF를 확인한 뒤 Shape를 누릅니다.
  • AI·브러쉬·폴리곤·라벨 단축키 사이의 중복 지정을 막습니다. 기존 설정은 유지합니다.
  • 라벨·옵션·메뉴 구조를 확인할 수 없으면 잘못된 설정으로 시작하지 않고 안내합니다.
  • 2.1.4 QA 보고서의 별도 문제와 N 중복 지정 동작은 이번 변경 범위에 포함하지 않았습니다.

2.1.4 · 배포 버전명 변경

  • 요청한 배포 번호에 맞춰 2.1.3 → 2.1.4로 변경했습니다.
  • manifest.json, 팝업, 가이드의 버전 표기와 배포 ZIP 이름을 갱신했습니다.
  • 22개 패키지 파일을 비교해 위 세 파일의 버전 문자열만 달라졌는지 확인했습니다.
  • 기능 코드는 2.1.3과 같습니다. N 중복 지정 시 시작·완료를 구분하는 수정은 포함하지 않았습니다.

2.1.3 · 화면 밖으로 잘리는 오버레이 수정

  • 화면상의 실제 좌표와 CSS 위치 좌표를 섞어 계산하던 부분을 수정했습니다.
  • 현재 보이는 화면 영역과 오버레이의 실제 크기를 기준으로 창 전체가 화면 안에 들어오도록 위치·크기를 보정했습니다.
  • CSS 확대, 상위 요소의 위치·배율 변화, 확대된 화면 영역, 브라우저 창 크기 변경, 저장된 화면 밖 좌표를 처리했습니다.
  • 이미 열린 창도 화면 변화에 따라 다시 보정하도록 했습니다.
  • 창이 일부만 보여도 정상 표시로 판단하던 상태 검사를 수정했습니다.
  • 별도 Chrome 환경과 모의 CVAT 화면을 사용한 전체 검사 443개를 통과했습니다.

2.1.2 · 오버레이 복구와 전체화면 표시 수정

  • 팝업에 라벨 선택창 복구를 제공해 위치·크기·투명도·최소화 상태를 기본값으로 되돌리도록 했습니다.
  • 숨김 스타일도 초기화하되, 선택 라벨과 단축키 설정은 유지하도록 했습니다.
  • CVAT 요소 전체화면에서는 오버레이를 전체화면 요소 안으로 옮기고, 해제하면 문서 루트로 되돌리도록 했습니다.
  • 복구 결과의 실제 표시 상태를 확인하고, 구버전 코드가 남은 탭에는 RELOAD 안내를 표시하도록 했습니다.
  • 이후 사용 중 창이 반쯤 화면 밖에 남는 문제가 보고되어 2.1.3에서 위치 보정을 추가로 수정했습니다.

2.1.1 · N 라벨 연동 실패 수정

  • CVAT 기본 작업 공간의 이름을 standard로 비교하던 오류를 실제 값인 Standard로 수정했습니다.
  • 기본 작업 공간에서도 N 시작이 차단되던 조건을 바로잡고, 같은 잘못된 값을 사용하던 테스트도 수정했습니다.
  • 연동 실패 시 STORE·WORKSPACE·BRIDGE 등의 고정된 확인 코드를 표시하도록 했습니다.
  • 오류 안내에 작업 ID·이미지 이름·라벨 값 등 작업 데이터를 포함하지 않도록 했습니다.

2.1.0 · N으로 이전 도구를 불러올 때 선택 라벨 적용

  • 오버레이·팝업·라벨 단축키로 선택한 라벨을 CVAT 기본 N 이전 도구 호출에도 적용했습니다.
  • 새 객체를 시작하기 직전에 다음 라벨만 바꾸고, 이전 도구·객체 종류·AI 모델·그리기 옵션은 보존하도록 했습니다.
  • 그리기·편집 중에는 현재 객체의 라벨을 유지하고 CVAT의 기존 N 완료·종료 처리로 넘기도록 했습니다.
  • CVAT 상태와 선택 라벨의 호환성을 확인할 수 없는 경우 시작을 중단하고 안내하도록 했습니다.
  • 이 연결은 CVAT 내부 상태 구조를 이용하므로 CVAT 버전에 따른 호환성 확인이 필요합니다.

2.0.0 · 이동·크기 조절 가능한 라벨 오버레이

  • 확장 팝업을 계속 열지 않아도 작업 화면에서 라벨을 선택할 수 있는 라벨 선택 오버레이를 만들었습니다.
  • 제목을 드래그해 이동하고, 색상칩과 이름을 눌러 다음 객체의 라벨을 선택하도록 했습니다. 지정한 라벨 단축키도 함께 표시했습니다.
  • 하단에 투명도 0~70% 조절을 추가하고, 위치·크기·투명도·최소화 상태를 저장하도록 했습니다.
  • 예시 라벨 6개를 사용하는 데모를 만들고, 팝업에 라벨 선택창 사용 켜기·끄기를 추가했습니다. 실제 확장은 해당 작업의 전체 라벨을 표시합니다.
  • 창을 줄이면 목록에 스크롤이 생기고, 넓히면 2열·3열 등으로 자동 배치되는 반응형 목록을 구현했습니다.
  • 창의 네 변과 네 모서리 어디서든 크기를 조절하도록 했습니다.
  • ×는 완전히 끄기, −는 작은 버튼으로 최소화로 구분하고, 최소화된 버튼도 드래그로 움직일 수 있도록 수정했습니다.
  • 오버레이 조작이 CVAT 캔버스 입력으로 전달되는 문제와 슬라이더·포커스·보조키 해제 처리를 보완했습니다.

1.9.0 · 라벨 선택 단축키와 우선 처리

  • 확장프로그램에서 사용하는 다음 객체의 라벨을 단축키로 선택할 수 있도록 했습니다.
  • 라벨별 단축키 지정·변경·해제를 추가하고, 선택한 라벨을 다음 AI·새 마스크 시작에 적용했습니다.
  • 등록한 확장 단축키를 먼저 처리하고, 키 반복·해제도 함께 관리하도록 했습니다.
  • 라벨을 바꾼 직후 도구를 실행해도 새 선택을 사용할 수 있도록 저장 전 선택값을 즉시 반영했습니다.
  • 기존 객체나 현재 그리는 객체의 라벨을 바꾸는 CVAT 자체 기능과는 별도로 동작하도록 했습니다.

1.8.0 · Space를 누른 채 화면 이동

  • 브러쉬를 사용하는 중 Space + 왼쪽 드래그로 화면을 이동하는 기능을 추가했습니다.
  • CVAT의 기본 가운데 버튼 이동 동작을 이용해, 브러쉬를 해제하거나 다시 선택하지 않고 이동하도록 했습니다.
  • Space와 마우스를 놓으면 이어서 그릴 수 있도록 하고, 팝업에서 기능을 켜고 끌 수 있게 했습니다.
  • 키·마우스를 놓는 순서, 창 포커스 상실, 이미 진행 중인 스트로크, 작업 화면 변경에 따른 입력 정리를 보완했습니다.
  • 가이드에 Space 이동 사용법과 관련 팝업 화면을 추가했습니다.

1.7.3 · 실제 확장 화면을 넣은 적용 가이드

  • 가이드를 업데이트 → 확장 켜기 → 라벨 선택 → 단축키 지정 → 작업 중 사용 순서로 쉽게 다시 작성했습니다.
  • 실제 확장 코드를 예시 라벨·모의 API와 함께 실행한 로컬 시연 화면을 캡처해 이미지 5장을 넣었습니다.
  • ZIP 설치와 웹스토어 업데이트 방법을 구분하고, V·B는 직접 지정하는 예시 키임을 설명했습니다.
  • 이미지를 확장에 포함해 오프라인에서도 가이드를 볼 수 있도록 했습니다.
  • 도구 기능 코드는 1.7.2와 동일하게 유지했습니다.

1.7.2 · 도구 창만 열리고 실행되지 않는 오류 수정

  • AI와 새 마스크 모두 메뉴만 열리고 Interact·Shape까지 진행되지 않는 현상을 조사했습니다.
  • CVAT가 메뉴를 열면서 보내는 버튼 없는 마우스 이벤트를 실제 왼쪽 버튼 누름으로 잘못 기록하던 처리를 수정했습니다.
  • 버튼 없는 알림은 무시하고, 실제 마우스 버튼을 누른 상태만 추적하도록 했습니다.
  • AI·마스크 메뉴의 같은 이벤트를 재현해 실행이 중단되는 문제를 검사했습니다.

1.7.1 · 색상과 이름을 하나의 선택 목록으로 통합

  • 라벨 드롭다운과 별도 색상 선택 UI를 하나의 목록으로 합쳤습니다.
  • 각 행에 색상칩 + 라벨 이름을 함께 표시하고, 선택한 행을 강조했습니다.
  • 선택 즉시 저장, 목록 새로고침, 직접 입력 대체 경로는 유지했습니다.

1.7.0 · 다른 도구에서 단축키로 바로 전환

  • AI·새 마스크 단축키 실행 앞에 Esc를 전달하도록 했습니다.
  • 활성 도구가 해제된 것을 확인한 뒤 메뉴 열기 → 라벨 선택 → Interact 또는 Shape 실행으로 이어지도록 했습니다.
  • 사용자가 직접 Esc를 누르지 않아도 다른 도구로 전환할 수 있게 했습니다.
  • 키를 계속 누르고 있거나 전환이 이미 진행 중이면 중복 실행하지 않도록 했습니다.
  • 이 동작은 현재 작업을 완료하는 기능이 아니라 Esc에 따른 취소·전환입니다. 진행 중인 그리기가 취소될 수 있습니다.

1.6.1 · 라벨 대표색 표시

  • CVAT 라벨의 대표색을 읽어 색상칩으로 표시했습니다.
  • 선택한 라벨의 색상 표시와 대표색으로 선택 목록을 추가했습니다.
  • 색상 항목을 눌러도 같은 라벨 선택·저장 절차를 사용하도록 했습니다.
  • 색상을 읽지 못한 경우 임의의 색을 만들지 않고, Labels 탭을 열어 새로고침하도록 안내했습니다.

1.6.0 · 이 탭의 라벨 선택

  • 기본 라벨 이름을 매번 직접 입력하는 불편을 줄이기 위해 이 탭의 라벨 선택 기능을 추가했습니다.
  • 현재 작업에 등록된 전체 클래스 목록을 읽고, 아직 사용하지 않은 클래스도 표시하도록 했습니다.
  • Overview의 합계 행은 제외하고, 목록에서 라벨을 선택하면 다음 객체의 기본 라벨로 저장하도록 했습니다.
  • 목록 새로고침, 이름 중복 확인, 목록을 읽지 못했을 때의 직접 입력 경로를 마련했습니다.
  • 작업별 라벨 목록은 저장하지 않고, 선택한 이름만 기존 설정에 저장하도록 했습니다.

1.5.0 · 한글 UI와 내장 가이드

  • CVAT의 기본 휠 버튼 드래그 이동과 문제 해결 방법을 안내했습니다.

1.4.1 · 단축키 이벤트 충돌 보완

  • 확장이 처리하기로 한 키를 CVAT의 일반 키 처리보다 먼저 받을 수 있도록 이벤트 처리 위치를 변경했습니다.
  • 키를 길게 누를 때의 반복 입력과 키 해제까지 처리해, 확장 실행 후 같은 입력이 CVAT에 다시 전달되는 경우를 줄였습니다.
  • Ctrl·Shift·Alt·Cmd 해제는 전달해 보조키가 눌린 상태로 남지 않도록 했습니다.
  • 입력창·한글 조합·지원하지 않는 화면에서의 예외 처리와 수동 확인 가이드를 보완했습니다.
  • 별도로 준비했던 0.1.1 스토어용 번호는 취소하고 개발판과 같은 1.4.1 이름·버전을 사용하기로 했습니다. releases/0.1.1/은 취소된 준비 기록입니다.

1.4.0 · Mac 키 표시와 배포 준비

  • Mac에서는 Alt를 Option, Meta를 Cmd로 표시하고 Ctrl과 Cmd를 구분하도록 했습니다.
  • 브라우저·운영체제가 사용하는 키 조합을 지정하면 충돌 가능성을 안내하도록 했습니다.
  • Cmd + 휠 등 기본 브라우저 입력을 유지하고, Mac 키 입력을 모의한 검사를 추가했습니다.
  • 확장 아이콘과 웹스토어 업로드용 ZIP, 설치·권한·개인정보 처리 안내 자료를 준비했습니다.

1.3.1 · 브러쉬 휠 조절 개선

  • 브러쉬 크기 조절을 Alt + 휠 / Shift + 휠로 변경했습니다.
  • Ctrl + 휠과 터치패드 핀치는 기존 확대·축소 동작으로 남겼습니다. 이전에 저장된 Ctrl + 휠 설정은 Alt로 이전했습니다.
  • 조절 폭을 한 단계에 5px → 1px로 줄여 미세하게 조절할 수 있도록 했습니다.
  • 작은 터치패드 입력을 누적하고, Shift + 휠이 가로 방향 입력으로 들어오는 경우도 처리했습니다.

1.3.0 · 새 객체의 기본 라벨 지정

  • 팝업에 새 객체에 사용할 기본 라벨 이름을 직접 입력하고 저장하는 기능을 추가했습니다.
  • AI·새 마스크 도구를 시작하기 전에 지정한 라벨을 선택하고, 선택 결과를 확인하도록 했습니다.
  • 정확히 일치하는 라벨이 없거나 이름이 중복되면 임의의 다른 라벨로 시작하지 않도록 했습니다.
  • AI 모델과 다른 도구 옵션은 유지하고, 기존 객체의 라벨은 변경하지 않도록 했습니다.

1.2.0 · 메뉴 열기에서 실제 도구 시작까지

  • AI 단축키가 메뉴를 연 뒤 Interact까지, 새 마스크 단축키가 메뉴를 연 뒤 Shape까지 실행하도록 확장했습니다.
  • 메뉴가 준비될 때까지 기다린 뒤 실행하고, 연속 입력으로 중복 실행되지 않도록 처리했습니다.
  • 활성 마스크 캔버스에서 수정키와 마우스 휠로 브러쉬·지우개 크기를 조절하는 기능을 추가했습니다.
  • 이때는 Alt 또는 Ctrl + 휠을 지원했고, 한 단계에 5px씩 조절했습니다. 이후 1.3.1에서 조합과 조절 폭을 변경했습니다.
