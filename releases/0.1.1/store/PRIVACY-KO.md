# CVAT Sidebar Shortcuts 개인정보 처리 안내

적용 버전: 0.1.1 · 작성일: 2026-10-02

## 처리하는 정보와 목적

CVAT 도구를 키와 휠로 조작하기 위해 현재 활성 탭의 URL이 CVAT 작업 경로인지 확인합니다. Enable한 탭에서는 필요한 사이드바 도구, 클래스 선택 메뉴와 클래스 이름, 브러시 크기 입력 상태를 기기 내에서 읽고 해당 컨트롤을 조작합니다. 단축키 입력과 휠 방향·수정키·포인터 위치는 일시적으로 확인합니다. 텍스트 입력 중의 키와 IME 조합은 실행에서 제외하며, 입력 내용이나 키 입력 기록을 저장하지 않습니다.

Mac 표시를 위해 Chrome이 제공하는 기본 플랫폼 이름을 기기 내에서 확인합니다. 이를 저장하거나 외부로 보내지 않습니다.

## 저장·보관·삭제

사용자가 선택한 AI/새 마스크 단축키, 기본 클래스 이름, 휠 사용 여부와 Alt/Shift 선택만 해당 Chrome 프로필의 `chrome.storage.local`에 저장합니다. 다른 기기나 프로필과 동기화하지 않습니다. 사용자가 변경하거나 확장을 제거할 때까지 유지됩니다. 팝업의 Clear는 해당 단축키를 지우며, 클래스와 휠 설정은 별도로 변경할 수 있습니다. 전체 설정은 확장을 제거하면 삭제됩니다. Chrome 프로필을 직접 복사하거나 백업하는 경우에는 그 환경의 보관 정책이 적용될 수 있습니다.

현재 탭 URL, 클래스 메뉴 목록, 브러시 입력 상태, 포인터 위치와 이벤트 이력은 지속 저장하지 않습니다. 사용자가 직접 설정한 기본 클래스 이름만 설정으로 보관합니다.

## 외부 전송·공유

확장 자체에는 서버 요청, 광고, 분석/추적, 원격 코드, 이미지 읽기·픽셀 접근·스크린샷·업로드 기능이 없습니다. 개발자나 제3자에게 사용 데이터를 전송·판매·공유하지 않습니다. 회사 이미지, 주석 결과, 계정 정보와 인증 정보에 접근하여 수집하지 않습니다.

확장이 시작하는 Interact 등 CVAT의 정상 기능은 이후 사용자의 조작에 따라 CVAT가 원래 구성한 AI 모델이나 서버를 사용할 수 있습니다. CVAT 자체의 처리·저장 통신은 이 확장과 별도이며 사용 중인 CVAT 서비스의 정책을 따릅니다. Chrome Web Store의 설치·업데이트 및 Google의 서비스 데이터 처리도 이 확장 자체의 통신과 별도입니다.

## 접근 범위

권한은 activeTab, scripting, storage 세 가지입니다. 모든 사이트에 대한 상시 호스트 권한이나 백그라운드 페이지가 없습니다. 사용자가 Enable한 현재 CVAT 작업 탭에서만 활성화하며, 새 탭이나 페이지 새로고침 후에는 다시 Enable해야 합니다. 팝업의 Pause로 해당 탭에서 중지할 수 있습니다.

정보는 공개한 CVAT 도구 조작 목적에만 사용합니다. 광고, 별도 분석, 판매 또는 기능과 무관한 용도로 사용하지 않습니다.
