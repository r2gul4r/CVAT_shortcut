## 2.11.0 — Job별 라벨 숨김과 1도 화면 정렬

- 라벨 오버레이의 눈 버튼으로 선택한 라벨을 Job 전체에서 숨기거나 다시 표시합니다. 프레임 이동 후에도 유지하고 Job별로 기억합니다.
- 화면 탭에 1도 단위 회전, 직접 각도 입력, 0도 복귀를 추가했습니다. 원본 이미지와 라벨 좌표를 유지하며 현재 프레임의 표시 각도만 바꿉니다.
- 화면에 고정된 수평·수직 격자를 추가했습니다. 간격·선명도·색상을 조절해 바코드를 정렬한 뒤 스켈레톤을 그릴 수 있습니다.
- 회전 중 확대·축소의 좌표를 함께 보정합니다. 브러쉬·AI 도구로 전환하면 0도로 돌아갑니다. 그리기·편집·재생 중에는 각도 변경을 막습니다.
- 라벨 숨김은 그릴 라벨 선택과 독립적으로 동작합니다. 숨김 모두 해제로 확장이 숨긴 라벨을 복구하며, 기존 CVAT 수동 숨김은 유지합니다.
