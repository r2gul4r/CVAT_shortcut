## 2.11.1 — 회전 이미지에서 수평 스켈레톤 생성

- 이미지를 돌렸을 때 새 스켈레톤 생성 틀까지 기울던 문제를 수정했습니다. 새 생성 틀은 화면 수평·수직을 유지합니다.
- 두 모서리 클릭 또는 드래그로 완성한 관절을 원본 이미지 좌표로 변환합니다. 0도 복귀 후에도 이미지와의 위치가 유지됩니다.
- Esc 취소, N 완료, 확대·이동을 처리합니다. 프레임 변경 또는 이미지 밖 관절이 있으면 생성을 취소하며, 지원하지 않는 CVAT 버전은 0도 복귀를 안내합니다.
- 기존 객체, 붙여넣기·다시 그리기와 0도 생성은 CVAT 기본 동작을 유지합니다.
