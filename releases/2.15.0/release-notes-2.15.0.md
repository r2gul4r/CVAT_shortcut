## 2.15.0 — 폴리곤·스켈레톤 자동 그룹화

- 폴리곤 윤곽 안의 모든 관절을 검사하여 폴리곤 + 스켈레톤을 그룹화합니다. 폴리곤 안에 여러 스켈레톤이 있으면 하나의 그룹으로 묶습니다.
- 박스와 폴리곤이 같은 스켈레톤을 포함하면 기존 박스를 유지하고 함께 그룹화합니다. 폴리곤만 있는 새 작업도 지원합니다.
- 기존 박스 + 스켈레톤 그룹에도 새 폴리곤을 추가할 수 있습니다. 그룹 전체가 해당 묶음에 있을 때만 처리하며 CVAT 기본 그룹화로 새 그룹 번호가 부여됩니다.
- 겹치는 여러 박스·여러 폴리곤, 잠금·Track, 자기 교차 폴리곤과 소속이 불명확한 기존 그룹은 제외합니다. 검사 후 적용하며 좌표와 객체 수를 유지합니다.
