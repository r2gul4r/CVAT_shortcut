CVAT Sidebar Shortcuts 2.2.0

• 새 폴리곤 도구에 원하는 단축키를 지정할 수 있습니다.
• 라벨 선택 오버레이에서 고른 라벨이 폴리곤에도 적용됩니다.
• 단축키 실행 시 기존 도구를 취소하고 Number of points는 공란, Simplify는 OFF로 설정한 뒤 Shape로 시작합니다.
• 기존 AI·브러쉬·라벨 단축키와 중복되는 키는 지정할 수 없습니다.
• 도구 단축키를 상단에 모으고 라벨 목록·설정 화면을 간결하게 정리했습니다.
• 실제 확장 팝업이 좁게 열리며 도구 이름이 세로로 줄바꿈되는 폭 계산 문제를 수정했습니다.
• 기존 설정은 유지되며 폴리곤 단축키는 미지정 상태로 추가됩니다. 초기 2.2.0의 폴리라인 키를 지정했다면 폴리곤으로 이어받습니다.

사용 방법
1. 확장을 업데이트한 뒤 CVAT 작업을 저장하고 페이지를 새로고침합니다.
2. 확장 팝업에서 이 CVAT 탭에서 사용을 누릅니다.
3. 새 폴리곤 → 지정에서 원하는 키를 설정합니다.
4. 오버레이에서 라벨을 선택하고 지정한 키를 누릅니다.

2.1.4 QA의 별도 문제와 N 중복 지정 시 완료 동작은 변경하지 않았습니다.
