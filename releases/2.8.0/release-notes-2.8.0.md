## 2.8.0 — 선택 라벨 스캔 편집과 HTTP 범위 지정 오류 수정

- HTTP로 접속하는 사내 CVAT에서 범위 지정 후 crypto.randomUUID is not a function 오류가 발생하던 문제를 수정했습니다.
- 검수의 삭제·라벨 변경에서 편집할 라벨을 고르고 선택 라벨 스캔을 누르면, 해당 라벨이 있는 프레임과 객체 수를 새로 보여줍니다. 누락 검수 결과를 편집으로 가져오는 버튼은 제거했습니다.
- 스캔한 프레임을 30개씩 확인하고 번호·구간 또는 검색된 전체를 선택합니다. 대상 확인에서 라벨·프레임·객체 수를 검토하고 체크한 뒤 삭제하거나 다른 라벨로 변경합니다.
- 선택 라벨 변경, 스캔 후 데이터 변경 또는 5분 만료 시 다시 스캔하도록 처리했습니다. 편집 전 저장 확인과 적용 후 결과 확인을 유지합니다.
- 팝업과 작업 오버레이에 같은 흐름을 적용했습니다. Track은 검색된 전체에서만 편집하며 Tag·Skeleton·잠금·보호 객체의 기존 제한을 유지합니다.
