# 2.3.0 연결 상태 팝업 검증

개인 연결 상태 기능의 소스와 설치 ZIP을 검증했습니다. 이 보고서는 로컬 검증 결과이며, GitHub 릴리스와 웹스토어 자동 제출 결과는 [Actions](https://github.com/r2gul4r/CVAT_shortcut/actions)에서 별도로 확인합니다.

## 사용

`C:\git\cvat_shortcut\extension`을 로드한 확장을 새로고침한 뒤 팝업 상단 **연결 상태**에서 **측정 시작** 또는 **이 CVAT 서버에서 자동 측정**을 켭니다. 기존 설정은 **단축키** 화면에 있습니다. 통계는 팝업 안에서만 표시하며 팝업을 닫아도 측정은 계속됩니다. 이전 버전의 연결 상태창이 남아 있다면 CVAT 작업을 저장한 뒤 페이지를 새로고침하면 제거됩니다.

## 검증

- 브라우저 회귀검사 453개(기존 단축키 및 라벨 기능, 새 연결 상태 화면 13개 포함), 연결 상태 로직·워커·팝업 단위검사 38개, 실제 Chrome 확장 통합검사 10개, 라벨 로직 12개, Chrome 실행 환경 15개, 배포 실패·재시도 처리 34개: 총 562개 통과.
- 실제 localhost 저장 PATCH, AI POST, HTTP 503 요청이 팝업의 종류별 건수와 오류에 반영됩니다.
- 화면 전환·팝업 종료 동안 측정이 유지되고 다시 열면 최신 결과를 읽습니다. 페이지에 연결 상태 DOM을 생성하거나 스크립트를 주입하지 않습니다.
- 콘텐츠 쪽 타이머 없이 서비스 워커를 중단한 뒤에도 실제 요청이 워커를 깨워 집계됩니다. 새로고침과 Job 이동 후 자동 측정, 자동 설정 해제 후 비활성 유지를 확인했습니다.
- 새 세션 복구는 영구 설정만 남긴 새 워커로 검증했습니다. 전체 Chrome 종료/재실행과 실제 권한 승인 창은 자동화하지 않았습니다.
- 실제 Chrome 검사는 운영 manifest 그대로 권한 없는 시작과, localhost 권한만 미리 부여한 테스트 복사본을 사용했습니다. 개인 브라우저·회사 데이터에는 접근하지 않았습니다.

## 범위

허용한 서버의 선택한 Job 탭에서 같은 origin의 메인 프레임 `/api/` 요청을 관찰합니다. 화면에는 연결 상태 오버레이가 없습니다. 라벨 선택 오버레이와 단축키는 기존 기능을 유지합니다. API 응답 시간은 AI 비동기 작업 전체 완료 시간이나 저장 결과의 정확성을 보증하지 않습니다.

추가 서버 요청·외부 전송 없이 최근 5분/최대 300건의 통계만 세션 저장소에 보관합니다. 자동 측정 서버 목록은 로컬 설정으로 저장합니다. 팀 대시보드·통계 공유·수집 서버는 포함하지 않습니다.
