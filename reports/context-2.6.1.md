# 2.6.1 확장 연결 종료 오류 수정

## 원인과 재현

Chrome에서 확장을 업데이트·다시 로드하면 기존 CVAT 탭의 확장 연결은 무효가 되지만, 이미 삽입된 오버레이와 이벤트 핸들러는 남을 수 있습니다. 기존 코드는 × 클릭 시 `chrome.storage.local.set()`을 직접 호출했습니다. 이때 Promise가 반환되기 전에 동기 예외가 발생하므로 뒤의 `.catch()`로 처리하지 못했습니다.

수정 전 코드를 별도 Chrome 프로필에서 실제로 다시 로드한 다음 ×를 클릭해 다음 오류를 재현했습니다.

```text
Error: Extension context invalidated.
at action (overlay.js:246:30)
at pointer (overlay.js:326:46)
```

사용자가 제공한 문구와 일치합니다. 사용자의 정확한 클릭 시점은 제공되지 않았습니다.

## 수정

- 화면 갱신·키보드·마우스·저장 전에 확장 연결을 확인하고, 연결이 끝나면 오래된 오버레이·타이머·리스너를 정리합니다.
- 검수와 연결 상태 화면도 함께 종료합니다. 연결이 무효가 된 뒤 리스너 정리 API가 던지는 예외도 처리합니다.
- 이전 컨트롤러의 단축키·대기 중인 도구 호출·붙여넣기 반복을 중지하고, 작업 저장 후 CVAT 새로고침을 안내합니다.
- 닫기 설정 저장의 동기 예외도 Promise 체인에서 처리합니다. 일반 저장 실패 시 오버레이를 복구하는 기존 동작은 유지합니다.
- CVAT 페이지를 자동으로 새로고침하지 않습니다. 기존 설정·주석을 삭제하지 않으며 권한을 추가하지 않습니다.

## 검사

| 검사 | 통과 |
| --- | ---: |
| 실제 확장 재로드: 라벨·검수·연결 상태 | 3 |
| 기존 DOM·단축키·팝업·오버레이 | 478 |
| 라벨 로직 | 12 |
| Chrome 검수·작업 오버레이 통합 | 30 |
| MAIN·ISOLATED 통신 | 17 |
| 릴리스·패키징 | 39 |
| **이번 수정 관련 합계** | **579** |

최종 실패 0개. 실제 재로드 검사에서는 라벨·연결 상태의 클릭 경로와 검수의 무입력 타이머 경로를 확인했습니다. 오래된 오버레이 제거, 안내 표시, 추가 조회 없음, 처리되지 않은 예외 없음까지 검사했습니다. 이후 GitHub 검사에도 세 재로드 사례를 추가했습니다.

검사 도중 기존 Chrome 테스트 팝업 재열기에서 자동화 연결이 멈춘 사례가 있었습니다. 다음 팝업을 열 때 이전 대상 ID를 제외하도록 검사 도구를 보완했고, 전체 통합 검사 30개가 통과했습니다. 릴리스 검사의 임시 디렉터리 권한 오류는 정상 임시 디렉터리 권한으로 재실행해 통과했습니다.

별도 Chrome 프로필·localhost 합성 CVAT만 사용했습니다. 실제 사내 CVAT와 개인 브라우저에는 접근하지 않았습니다. 기존 2.6.0 전체 691개를 모두 다시 실행한 결과는 아닙니다.

## 적용

이미 로드된 이전 버전 코드는 새 파일만 수정해도 자동 교체되지 않습니다.

1. CVAT 작업을 저장합니다.
2. `chrome://extensions`에서 `C:\git\cvat_shortcut\extension`의 로컬 확장을 새로고침합니다.
3. CVAT 페이지도 새로고침하고 확장을 다시 활성화합니다. 팝업 버전 **2.6.1**을 확인합니다.

배포 ZIP: `releases/2.6.1/cvat-sidebar-shortcuts-2.6.1-ko.zip`. 35개 런타임 파일과 SHA-256은 같은 폴더의 `build-audit.json`에서 확인할 수 있습니다. 이번 작업에서는 GitHub 푸시·스토어 제출을 실행하지 않았습니다.
