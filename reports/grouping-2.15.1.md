# 2.15.1 그룹화 제한 완화

## 변경 동작

- 스켈레톤 관절 bounding box의 중심이 들어간 도형을 연결합니다. 모든 관절의 완전 포함 조건을 제거했습니다.
- 폴리곤·박스·스켈레톤을 함께 그룹화하며 박스가 없는 경우 폴리곤·스켈레톤으로 처리합니다. 박스만 있는 기존 작업도 지원합니다.
- 여러 박스·폴리곤이 같은 스켈레톤으로 연결되면 연결된 전체를 한 그룹으로 묶습니다. 넓은 도형이 여러 대상의 중심을 포함하면 함께 묶이므로 적용 전 미리보기 ID를 확인해야 합니다.
- 기존 그룹 번호 또는 다른 프레임의 그룹 구성원 때문에 제외하지 않습니다. 매칭된 객체만 새 그룹으로 이동합니다. 비대상 객체와 다른 프레임 객체는 기존 그룹 번호를 유지합니다.
- 기존 그룹 추가 체크박스를 제거했습니다. 완전히 같은 그룹인 대상은 중복 처리하지 않습니다.
- 좌표·라벨·객체 수 보존 검사, 잠금·보호·Track 제외, 유효하지 않은 좌표 제외, 검사 후 변경 확인과 CVAT undo는 유지합니다.

## 검증

- 단위 테스트 83개 통과: 다른 프레임/같은 프레임 비대상 그룹원 보존, 서로 다른 기존 그룹 합치기, 경계 밖 관절의 중심 매칭, 복수 도형, 독립 대상, 중복 실행, 좌표/라벨 보존 및 undo.
- 합성 CVAT 데이터를 사용하는 임시 실제 Chrome MV3 테스트 11개 통과: 다른 프레임에 기존 그룹원이 있는 상태에서 폴리곤 추가, 미리보기와 적용, 좌표/객체 보존 및 Job 전환.
- 릴리스 회귀 테스트 39개 통과. 합계 133개, 실패 0개.
- 회사 CVAT의 실제 주석은 수정하거나 저장하지 않았습니다. 실제 서버의 저장 후 재확인은 수행하지 않았습니다.

## 로컬 적용

작업 저장 → Chrome 확장 관리에서 C:\git\cvat_shortcut\extension 다시 로드 → CVAT 새로고침 → 화면 탭의 그룹 대상 검사.
설치용 파일: releases/2.15.1/cvat-sidebar-shortcuts-2.15.1-ko.zip.
이 수정은 로컬에 준비했으며 GitHub 푸시와 웹스토어 제출은 수행하지 않았습니다.
