# 2.15.2 폴리곤 그룹 누락 수정

## 원인과 변경

실제 CVAT 화면을 읽기 전용으로 조사해 SVG 폴리곤이 nonzero 채움 규칙으로 표시되는 것을 확인했습니다. 기존 구현은 윤곽선 자기 교차를 오류로 분류하고, 도형 하나가 오류여도 해당 프레임 전체의 그룹 검사를 중단했습니다.

- 자기 교차 폴리곤도 nonzero winding으로 포함 관계를 판정합니다. 면적의 부호 합이 0인 나비형 윤곽도 지원합니다.
- 중복 꼭짓점은 판정용 임시 배열에서만 정리하며 원본 주석 좌표는 변경하지 않습니다.
- 실제로 읽을 수 없는 도형만 제외하고 다른 도형의 검사를 계속합니다. 제외 도형 ID와 좌표 형식, 회전, 크기 제한 등 구체적인 이유를 표시합니다.
- 기존 2.15.1의 중심 기준 매칭, 기존 그룹 여부와 무관한 재그룹화, 잠금/보호/Track 제외, 적용 전후 변경 검증과 undo는 유지합니다.

영역 판정 기준: https://www.w3.org/TR/SVG2/painting.html#FillRuleProperty

## 검증

- 그룹 단위 검사 90개 통과: 자기 교차, 같은 방향 중복 감기, 반대 방향 감기, 구멍, 중복 꼭짓점, 오류 도형 분리, 좌표 보존과 undo.
- 합성 데이터를 사용한 실제 임시 Chrome MV3 검사 13개 통과. 브라우저의 SVG isPointInFill 결과와 자기 교차 도형의 그룹화 결과를 비교했습니다.
- 릴리스 검사 39개 통과. 총 142개, 실패 0개.
- 현재 문제 프레임에 표시된 도형 좌표로 수행한 읽기 전용 계산에서 스켈레톤 중심 3개 모두 해당 폴리곤에 포함됨을 확인했습니다. 회사 이미지와 객체 좌표는 테스트 파일이나 공개 저장소에 복사하지 않았습니다.
- 회사 CVAT의 그룹 적용·저장은 수행하지 않았습니다. 로컬 확장 재로드와 CVAT 새로고침 후 재검사가 필요합니다.
