# 2.15.3 그룹화 업데이트 잔류 수정

## 확인한 현상
사용자의 Job 탭에 새 자기 교차 지원 안내가 표시되지만 검사 결과는 이전 버전에만 있는 `폴리곤 좌표 오류·자기 교차 또는 미지원 회전` 문구를 반환했다. 화면은 최신 ISOLATED 코드이고 MAIN 실행 코드는 이전 버전이었다.

## 원인과 수정
이전 MAIN 코드의 __cvatShortcutsGroupV1 등록 플래그 때문에 새 코드가 실행 등록을 생략했다. 이전 익명 이벤트 핸들러를 제거할 수 없으므로 그룹 요청 이벤트와 등록 키를 2.15.3 버전별로 분리했다. 같은 빌드 중복 주입은 계속 차단한다. 주석·좌표 변경 로직은 이번 수정에서 바꾸지 않았다.

## 검증
- 그룹 계산·서비스 테스트: 90개 통과
- 실제 Chrome MV3 합성 환경: 14개 통과. 이전 플래그와 오류 반환 핸들러를 먼저 설치하고 새 확장을 활성화한다. 새 버전을 재주입한 뒤 검사·적용을 수행하여 이전 핸들러 호출 0회, 적용 중복 없음, 자기 교차 폴리곤 포함, 되돌리기를 확인했다.
- 릴리스 검사: 39개 통과
- 두 수정 JS 파일 구문 검사 및 git diff --check 통과
- 실제 회사 Job은 UI 상태만 확인했다. 저장·그룹 적용·새로고침은 실행하지 않았으며 회사 이미지나 좌표를 테스트에 복사하지 않았다.

## 적용
로컬 extension 폴더를 사용하는 Chrome 확장을 다시 로드하고 CVAT 탭에서 확장 팝업의 이 탭에서 사용으로 새 코드를 주입한다. 그룹 대상 검사를 새로 실행한다. 테스트는 페이지 새로고침 없이 구버전 코드와 공존하는 경우를 검증했다. 실제 사용자 Job의 적용 결과는 아직 미검증이다.
