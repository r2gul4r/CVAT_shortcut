# 2.15.4 이미지 가장자리 그룹 누락 보완

## 진단
사용자가 수동으로 그룹화한 두 프레임을 읽기 전용으로 검사했다. 두 사례 모두 스켈레톤 중심은 폴리곤 밖에 있고, 각각 관절 1개와 2개만 안에 있었다. 기존 중심점 판정은 폴리곤을 빈 도형으로 분류했다. 수동 그룹은 변경하지 않았다.

## 변경
중심점 또는 관절 하나 이상이 포함되면 폴리곤·박스와 연결한다. 원본 좌표와 라벨은 수정하지 않는다. 같은 그룹은 건너뛰고 잠금·Track·Outside 보호는 유지한다. 여러 도형에 걸친 관절도 연결할 수 있으므로 안내에 검사 목록 확인을 명시했다. 버전별 요청 채널도 2.15.4로 갱신했다.

## 검증
- 그룹 계산·서비스 테스트 95개 통과: 부분 관절 1개/2개, 회전 박스, 수동 그룹 보존, 되돌리기, 무관한 도형 제외 포함.
- 실제 Chrome MV3 합성 환경 15개 통과: 구버전 핸들러 잔류, 재주입, 부분 관절 매칭, 반복 검사, 원본 복구 포함.
- 릴리스 검사 39개 및 구문 검사·diff 검사 통과.
- 합성 좌표만 테스트에 사용했다. 회사 이미지·좌표는 저장하지 않았다.
- 실제 Job에서 새 버전으로 그룹 적용·저장은 실행하지 않았다. 로컬 코드와 설치 패키지 수정이며 배포하지 않았다.
