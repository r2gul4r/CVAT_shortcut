# 2.14.1 이미지 미리 받기 연결 오류 수정

첨부 오류는 공유 전역 `CVATBatchNativeContext`가 없는 상태에서 `.find()`를 읽는 경로와 일치합니다. 실제 회사 탭 내부는 조회하지 않았습니다. 이전 MAIN-world 그룹 sentinel만 남아 공유 객체의 생성이 생략되는 상황을 임시 Chrome에서 재현했습니다.

- 이미지 캐시가 그룹 모듈의 전역 객체에 의존하지 않고 현재 Job의 React store를 직접 탐색하도록 변경했습니다. Job/task ID, 2D, 프레임 범위와 현재 경로를 검증합니다.
- 공유 연결 객체 복구를 그룹 모듈의 중복 실행 방지 가드 앞에서 수행합니다. 기존 그룹 이벤트 핸들러를 중복 등록하지 않습니다.
- 연결이 불가능한 화면에는 한국어 안내를 표시합니다.
- 캐시/컨텍스트/그룹 단위 검사 82개 통과. 실제 MV3 회귀 14개 통과. 공유 객체 삭제 및 구버전 sentinel을 넣은 상태에서도 압축 데이터 다운로드·재사용·Job 전환·확장 reload 정리를 확인했습니다.
- 회사 CVAT에서 실제 이미지 디코딩 및 속도는 아직 검증하지 않았습니다.

적용: Chrome 확장 관리에서 `C:\git\cvat_shortcut\extension`을 다시 로드한 뒤 CVAT 작업을 저장하고 페이지를 새로고침합니다. 화면 → 이미지 미리 받기에서 실행합니다.
