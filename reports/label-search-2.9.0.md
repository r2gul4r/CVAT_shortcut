# 2.9.0 특정 라벨 프레임 찾기 검증

검수의 라벨 선택 목록에서 특정 라벨을 체크하고 **선택 라벨 찾기**를 누르면, 저장된 작업 중 그 라벨이 있는 프레임을 표시합니다. 기존 **누락 프레임 검사**는 유지합니다. 팝업과 오버레이 모두 동일한 화면과 Job별 마지막 결과를 사용합니다.

## 동작

- Shape와 Track의 가시 구간을 기존 검수 로직으로 계산합니다. 여러 선택 라벨은 OR로 모으고 프레임 번호를 중복 없이 정렬합니다.
- 삭제 프레임, 포함되지 않은 원본 프레임, Track Outside 구간과 Tag를 제외합니다. 원본 frame step이 있어도 CVAT의 프레임 번호를 사용합니다.
- 라벨별 필터, 30개씩 페이지 이동, 번호 클릭, 현재 CVAT 프레임 기준 이전·다음 이동을 지원합니다.
- 결과 복사·CSV는 검색 결과를 ‘있는 프레임’으로 출력합니다. 누락 결과는 기존 형식으로 출력하며 이전 버전의 저장된 누락 결과도 읽습니다.
- 선택 변경, 조회 실패와 Job 변경 때 이전 결과를 현재 결과처럼 표시하지 않습니다. 그리기 중 프레임 이동은 기존 방식으로 차단합니다.
- 기존 동일 서버 GET 조회만 사용합니다. 권한 추가·이미지 조회·외부 전송·주석 수정 없이 이름·ID·색상·프레임 구간 등 결과만 저장합니다.

|---|---:|---:|

| 일괄 편집 경계·오래된 미리보기 | 52 | 0 |

| 검수 화면 확장 재로드 | 1 | 0 |
| 배포·릴리스 실패 처리 | 39 | 0 |
| 합계 | 689 | 0 |

실제 Chrome은 별도 임시 프로필과 localhost의 합성 CVAT fixture를 사용했습니다. 실제 확장 API·조회·저장소·팝업·Shadow DOM 동작을 검사했지만, 회사 CVAT 서버의 데이터 및 설치 버전과의 동작은 이번 검사 대상이 아닙니다. 개인 Chrome 프로필과 회사 주석 데이터는 사용하지 않았습니다.

확인한 핵심 사례: 한 라벨 검색과 중복 객체, 여러 라벨 OR·필터, 누락·삭제 프레임 건너뛰기, 빈 검색 결과, 프레임 0, 팝업 재열기, 오버레이에서 생성한 결과를 팝업에 표시, 기존 누락 검사로 복귀, 조회 오류, Job 이동, 재로드 정리.

## 사용

CVAT 작업 저장 → 확장 다시 로드 → CVAT 페이지 새로고침 → 검수 → person 체크 → 저장 확인 → 선택 라벨 찾기 → 확인할 라벨 프레임에서 번호 클릭 또는 이전·다음 결과로 이동.

소스: `C:\git\cvat_shortcut\extension`

로컬 ZIP: `releases/2.9.0/cvat-sidebar-shortcuts-2.9.0-ko.zip`
