# 2.4.0 붙여넣기 반복 검증

사용자가 객체 하나를 직접 그리고 복사한 뒤, **Ctrl+V → 왼클릭 확정 → F**를 반복하는 기능을 추가했다. 반복 횟수는 제한하지 않는다. 시작은 팝업의 **붙여넣기 반복 → 반복 시작** 또는 직접 지정한 단축키로 한다. 저장 버튼을 자동으로 누르지 않는다. 화면 알림은 시작·중지·오류 때만 표시하고 반복마다 갱신하지 않는다.

## 사용 순서

1. 객체 하나를 직접 그리고 CVAT에서 Ctrl+C로 복사한다.
2. **처음 붙여넣을 프레임**으로 이동한다. 매크로는 시작할 때 자동으로 다음 프레임으로 이동하지 않는다.
3. 실행 단축키 또는 팝업의 반복 시작 버튼을 누른다. 팝업에서 시작하면 팝업이 닫힌다.
4. 마우스를 움직이지 않고 기다린다. **Esc** 또는 실행 키를 다시 누르면 중지한다.
5. 결과를 확인하고 CVAT에서 직접 저장한다. CVAT 자체 자동 저장 설정은 기존대로 동작한다.

## 구현과 중지 조건

- 반복마다 CVAT 내부 붙여넣기 키를 한 번 전달하고, 미리보기 준비 상태를 확인한 뒤 왼클릭으로 한 번 확정한다. 마우스 이동 이벤트를 보내거나 좌표를 다시 계산해 객체를 옮기지 않는다.
- 현재 프레임에 같은 종류·라벨의 객체 하나가 추가되고 그리기 모드가 끝난 것을 확인한 뒤 F를 한 번 전달한다. 다음 프레임이 준비되면 0.5초 뒤 반복한다.
- CVAT에 전달하는 합성 키는 해당 반복이 보내는 동안에만 기존 확장 단축키 처리를 우회한다. 사용자의 실제 키에는 기존 우선순위가 유지된다.
- 각 확인 단계는 최대 15초 기다린다. 확인 실패 시 자동 재시도하지 않고 중지한다. 이미 확정된 객체는 삭제하지 않는다.
- Esc, 실행 키 재입력, 다른 키·마우스 조작, 작업 화면 이탈, 확장 일시정지, Job 변경, 마지막 프레임에서 중지한다. 이미 요청한 프레임 로딩은 끝날 수 있지만 이후 붙여넣기는 실행하지 않는다.
- 복사한 객체의 라벨을 유지한다. 확장 라벨 오버레이 선택을 붙여넣기 객체에 덮어쓰지 않는다.

새 반복 검사는 마스크 미리보기 지연, 폴리곤 확정 대상, 프레임 로딩 지연, 중복 실행, Esc 취소, 프레임 이동 중 중지, 클립보드·Job 변경, 확정 실패 후 재시도 금지, 마지막 프레임 종료, 지원하지 않는 환경의 시작 차단을 포함한다. 실제 Chrome 입력으로 F8 시작·Esc 중지와 확장 F 단축키 충돌 처리를 검증했다.

검증에는 독립된 Chrome 프로필, 가상 CVAT DOM·React/Redux 상태, 실제 Mousetrap 키 처리와 실제 Chrome 실행 영역을 사용했다. **회사에 설치된 CVAT, 실제 회사 라벨링 데이터, 실제 저장 결과는 검증하지 않았다.** Mac 하드웨어 검사는 수행하지 않았다.

## 지원 범위와 데이터

CVAT 기본 2D 작업 화면에서 단일 Shape 복사만 지원한다. Track·다중 선택 붙여넣기·객체 필터·특수 프레임 탐색은 차단한다. 내부 클립보드, 캔버스 미리보기 상태 또는 프레임 경계를 확인할 수 없는 CVAT 버전에서는 시작하지 않는다. 호환성 확인은 사용자 환경에서 별도로 필요하다.

프레임 번호·준비 상태, 객체 ID·종류·라벨 ID만 페이지 안에서 일시적으로 비교한다. 객체 좌표·마스크 픽셀·이미지·속성을 추출하지 않으며 운영체제 클립보드를 읽지 않는다. 서버 API를 직접 호출하거나 작업 데이터를 외부로 보내지 않는다. 실행 단축키만 저장하며 매크로 실행은 자동 재개하지 않는다.
