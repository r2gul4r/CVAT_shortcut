# 2.15.0 폴리곤·스켈레톤 그룹화

## 동작

- 폴리곤만 있을 때: 폴리곤과 모든 관절이 포함되는 스켈레톤들을 한 그룹으로 묶습니다.
- 박스와 폴리곤이 함께 있을 때: 공통 스켈레톤으로 연결되는 박스·폴리곤·스켈레톤을 한 그룹으로 묶고 모든 객체를 보존합니다.
- 기존 박스 그룹: 기본으로 켜진 추가 옵션을 통해 새 미그룹 폴리곤을 추가합니다. 후보의 모든 박스·스켈레톤이 동일 기존 그룹이고, Job 전체 export에서 그 그룹의 구성원이 후보와 일치할 때만 처리합니다. 다른 프레임/객체/Track까지 연결된 그룹 또는 복수 기존 그룹은 유지합니다. 새 그룹 번호가 부여되며 이 점을 미리보기에도 표시합니다.
- 여러 박스 또는 여러 폴리곤으로 연결되는 모호한 묶음은 전체를 제외합니다. 반복 실행 시 이미 완료된 그룹은 유지합니다.
- 실제 윤곽의 점 포함 검사이며 경계는 포함합니다. 오목 폴리곤·CW/CCW·마지막 닫는 점을 지원합니다. 모든 관절을 검사하며 연결 선분 전체를 검사하지는 않습니다. 자기 교차·좌표 오류·0이 아닌 polygon rotation은 제외합니다.
- 좌표 오류가 있는 도형의 포함 관계를 추정하지 않도록 해당 프레임의 그룹 후보를 제외합니다. 잠금·보호·Track·삭제 프레임은 기존 제한을 유지합니다.
- CVAT native annotations.group과 undo를 사용합니다. 직접 HTTP 저장/삭제/이미지 조회를 하지 않습니다. 적용 후 저장은 CVAT 사용자/자동 저장 설정에 따릅니다.
- 검사 전후 export 및 native signature를 비교하고 적용 직전 재검사합니다. 적용 후 객체 수·좌표·라벨 및 비대상 그룹이 그대로인지 확인합니다. 부분 실패는 그대로 보고합니다.

## 검증

81개 단위 검사(기존 55 + 새 폴리곤 26), 실제 임시 Chrome MV3 11개, DOM 회귀 572개, 릴리스 검사 39개: 총 703개 통과 / 0 실패.
실제 MV3에서는 기존 박스 그룹에 폴리곤 추가, 다른 프레임의 폴리곤 + 스켈레톤 2개 그룹화, 다른 그룹 유지, 모든 객체·좌표 보존과 반복 실행을 검사했습니다. geometry 단위 검사는 오목 영역·삼각형 bbox 밖·경계·자기 교차·다중 도형 연결과 기존 그룹의 다른 프레임 구성원을 포함합니다.
회사 CVAT의 실제 주석 저장 후 재확인은 수행하지 않았습니다. 검증은 합성 데이터와 임시 Chrome에 한정합니다.

## 적용

Chrome에서 `C:\git\cvat_shortcut\extension`을 다시 로드하고, CVAT 작업을 저장한 뒤 페이지를 새로고침합니다.
화면 → 박스·폴리곤·스켈레톤 자동 그룹화 → 그룹 대상 검사 → 매칭된 대상 그룹화 → CVAT 저장.
ZIP은 `releases/2.15.0/cvat-sidebar-shortcuts-2.15.0-ko.zip`입니다. 이번 작업에서는 푸시나 스토어 제출을 하지 않았습니다.
