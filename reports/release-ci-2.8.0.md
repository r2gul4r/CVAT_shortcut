# 2.8.0 GitHub Actions 검수 테스트 실패 수정

실패 실행: https://github.com/r2gul4r/CVAT_shortcut/actions/runs/38853390598

`verify` 작업의 `Test review in real Chrome extension` 단계에서 `Runtime.evaluate`가 15초 뒤 타임아웃됐습니다. 이 실행에서는 GitHub 릴리스와 웹스토어 제출 단계가 실행되지 않았습니다.

## 원인

`tests/run-review-extension.mjs`가 Job 이동 후 팝업의 ‘작업 화면에서 연결 상태 열기’를 눌렀습니다. 이 버튼은 오버레이를 연 뒤 `window.close()`로 팝업을 닫습니다. 테스트는 그 직후 같은 팝업에서 추가 진단을 실행하고 응답을 기다렸습니다. 팝업이 먼저 닫히면 진단 Promise가 완료되지 않아 타임아웃됩니다.

로컬 독립 Chrome에서 버튼 클릭 뒤 300ms를 기다리도록 해 같은 위치·같은 오류를 재현했습니다. 기존 실행 속도에서는 진단이 팝업 종료 전에 끝나 우연히 통과했습니다.

## 변경 및 검증

- 팝업의 진단 조회를 오버레이 열기 버튼 클릭 전에 완료합니다.
- 버튼 클릭 뒤에는 살아 있는 Job 화면에서 오버레이를 확인하고 Chrome 대상 목록에서 팝업 종료를 확인합니다.
- 팝업을 테스트가 강제로 닫지 않고 실제로 자동 종료되는지도 검사합니다.
- 실제 Chrome 검수·오버레이 테스트 **37개 통과, 실패 0개**. Job 이동, 수동·자동 연결 측정, 연결 끊김 알림과 검수 네이티브 연결까지 완료했습니다.
- 확장 런타임과 ZIP은 변경하지 않았으며 버전은 **2.8.0**을 유지합니다. 테스트를 건너뛰거나 타임아웃을 늘려 통과시키지 않았습니다.

같은 버전의 일반 푸시는 검사만 실행하므로, 수정 커밋의 배포는 `workflow_dispatch`로 실행해야 합니다. 이전 2.8.0 실행은 릴리스 단계 전에 실패했으며 수정 시점에 v2.8.0 태그는 없었습니다. 기존 심사·릴리스 보호 로직은 유지합니다.
