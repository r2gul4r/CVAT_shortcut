# 2.11.1 회전 이미지의 수평 스켈레톤 생성

## 문제와 수정

2.11.0에서는 CVAT의 이미지 축을 기준으로 스켈레톤 생성 사각형을 만들었으므로 이미지가 돌아가면 생성 틀도 함께 기울었습니다. 좌표 역변환 검사만으로는 이 사용성 문제를 잡지 못했습니다.

2.11.1은 회전 상태에서 **새 스켈레톤을 만들 때** 화면 축에 맞춘 임시 SVG 미리보기를 사용합니다. 템플릿의 관절 ID·배열을 유지하고, 완료할 때 실제 CVAT SVG의 `getScreenCTM().inverse()`와 이미지 offset으로 각 관절을 원본 좌표로 변환합니다. CVAT의 기존 draw 완료 콜백에 전달하여 원래 객체 생성 흐름을 따릅니다. 확장이 별도 저장 API를 호출하지는 않으며 CVAT의 저장·자동 저장 정책은 그대로 적용됩니다.

- 두 모서리 클릭 또는 드래그로 생성, Esc 취소, N 완료를 처리합니다.
- 이미지 확대·이동 중 첫 기준점은 이미지에 붙어 있고 생성 틀은 화면 수평을 유지합니다.
- 프레임이 바뀌면 생성 중인 틀을 취소합니다. 이미지 밖 관절을 강제로 경계에 붙이지 않고 생성을 취소해 모양 변형을 방지합니다.
- 기존 객체·붙여넣기·다시 그리기·0° 생성은 native handler를 유지합니다.
- 지원 구조를 확인하지 못하면 회전 상태의 새 스켈레톤 생성을 막고 0° 복귀를 안내합니다.
- 새 권한·네트워크 통신·이미지 수집은 없습니다.

## 검증

| 검사 | 통과 | 실패 |
|---|---:|---:|
| DOM 회귀 검사 | 563 | 0 |
| 실제 MV3 화면 도구 | 12 | 0 |
| 실제 MV3 도구 단축키 | 7 | 0 |
| 실제 MV3 다시 로드 | 1 | 0 |
| 릴리스 자동화 단위 검사 | 39 | 0 |
| 합계 | 622 | 0 |

43개의 화면 도구 DOM 검사는 전체 DOM 검사에 포함됩니다. 그중 신규 11개는 여러 각도(1/17/90/179/270/343°), 두 클릭·드래그·완료·취소, 원본 좌표, offset, 화면 이동·확대, 프레임 변경, 이미지 밖 관절, 미지원 구조를 확인합니다.

별도 Chrome MV3 검사는 실제 생산 확장을 로드하고 신뢰된 마우스 이벤트로 드래그합니다. 미리보기의 폭·높이가 실제로 생기는지, 관절 행·열이 화면 수평·수직인지, 완료 후 투영 좌표가 미리보기와 일치하는지와 0° 복귀 후 원본 좌표 유지를 검사했습니다. 설정 오버레이는 실제 마우스 드래그로 캔버스 밖으로 옮겨 가림을 제거했습니다.

패키지 39개 파일을 소스와 바이트 단위로 비교합니다. 릴리스 설명·생성된 오버레이 뷰 일치, JS 정적 검사와 git diff 공백 검사를 통과했습니다.

## 적용과 남은 실사용 확인

Chrome 확장 관리에서 `C:\git\cvat_shortcut\extension`을 다시 로드하고 CVAT 작업을 저장한 후 페이지를 새로고침합니다. 격자로 이미지를 수평에 맞춘 다음 새 스켈레톤을 시작합니다.

위 결과는 합성 CVAT 계약/별도 Chrome 검증입니다. 회사 CVAT의 실제 템플릿·객체 생성·서버 저장·재접속 결과는 아직 확인하지 않았습니다. 실제 바코드 하나에서 생성 → 0° 복귀 → 저장·다시 열기 후 위치 확인이 남아 있습니다.
