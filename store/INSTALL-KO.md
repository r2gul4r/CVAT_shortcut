# CVAT Sidebar Shortcuts 1.4.1 설치·사용

Windows와 macOS용 Chrome 확장입니다. 최신 macOS의 실제 키보드·트랙패드 동작은 아직 검증하지 않았습니다.

Windows 소수 사용자에게 수동 파일럿을 진행하려면 [PILOT-KO.md](PILOT-KO.md)의 충돌 확인·피드백 체크리스트를 먼저 사용하세요. 확장이 CVAT의 사용자 지정 단축키를 자동으로 탐지하지 않으므로 본인의 CVAT Settings → Shortcuts에서 겹치지 않는 키를 골라야 합니다.

## 혼자 먼저 테스트하기

1. 회사 자료 대신 본인이 만든 테스트 이미지와 CVAT 작업을 준비합니다.
2. 새 컴퓨터에서는 ZIP을 풀고 Chrome의 `chrome://extensions`에서 **압축해제된 확장 프로그램을 로드합니다**. `manifest.json`이 있는 폴더를 선택합니다. 이미 설치했다면 기존 `extension` 폴더를 유지하고 확장 카드의 **새로고침**을 누릅니다.
3. 새로 로드하는 기능은 Chrome 개발자 모드가 필요합니다. 본인이 허용하는 개인 테스트 환경에서 직접 선택하세요. 관리 정책이 막으면 우회하지 마세요. 이 작업에서 브라우저 설정을 변경하지 않았습니다.
4. CVAT 작업 탭을 새로고침하고 확장 팝업에서 **Enable for this CVAT tab**을 누릅니다. 탭을 다시 열거나 새로고침하면 Enable을 다시 누릅니다.
5. AI tool / New mask (Brush tool)의 **Assign**을 누르고 원하는 키를 입력합니다. **Change**로 바꾸고 **Clear**로 지울 수 있습니다. 두 도구의 중복 키는 저장하지 않습니다. 처음에는 정해진 단축키가 없습니다.
6. **Default label for new objects**에 실제 CVAT 클래스 이름을 정확히 입력하고 **Save**를 누릅니다. 초기값은 `obstacle`입니다. 원하는 클래스가 `object`라면 직접 바꿔주세요.
7. AI 단축키는 해당 클래스 선택 확인 후 **Interact**, 새 마스크 단축키는 확인 후 **Shape**를 한 번 시작합니다. 모델과 다른 옵션은 CVAT에서 평소처럼 선택하세요.
8. Brush size에서 **Alt/Option + wheel** 또는 **Shift + wheel**을 선택합니다. Brush/Eraser가 활성화된 마스크 캔버스 위에서 휠을 움직이면 정규화된 한 단계마다 크기가 1씩 바뀝니다. 범위는 1~500이며 CVAT 입력의 더 좁은 범위가 있으면 따릅니다.

## Mac 키와 트랙패드

- **Option = Alt**, **Cmd = Meta**입니다. **Ctrl은 Cmd와 별도**로 저장됩니다. Windows에서 설정한 Ctrl을 Mac에서 자동으로 Cmd로 바꾸지 않습니다.
- 단축키는 입력된 글자보다 물리적인 키 위치(`KeyboardEvent.code`)를 사용합니다. Option으로 `å`가 입력돼도 A 위치 키로 인식합니다. 코드가 없거나 IME 조합/Dead key인 경우에는 추측하지 않습니다.
- Chrome/macOS 예약 키는 브라우저나 OS가 먼저 처리할 수 있습니다. 팝업에 충돌 가능성 안내가 뜨면 다른 키를 선택하세요. 모든 OS 예약 키를 찾아내는 기능은 아닙니다.
- Ctrl/Cmd가 포함된 휠, 핀치 확대, 수정키 없는 일반 스크롤은 확장이 가로채지 않습니다. Shift 휠이 가로 방향 이벤트로 전달돼도 브러시 크기에 사용할 수 있습니다.
- macOS의 자연스러운 스크롤 설정에 따라 손가락 이동 방향과 전달되는 이벤트 방향이 다를 수 있습니다. 본인 기기에서 한 단계씩 확인하세요.

## 안전한 개인 테스트 순서

Assign → Change → Clear → 팝업 다시 열기 순서로 설정 유지와 중복 경고를 확인합니다. AI와 새 마스크를 각각 시작해 정확한 클래스인지 확인합니다. 그다음 생성 중·기존 마스크 편집 중에 휠 한 단계가 1씩 바뀌는지 확인합니다. 다른 사이트, 텍스트 입력, 한글 조합, 일반 스크롤과 핀치가 평소처럼 작동하는지도 확인합니다. 잘못된 클래스 이름을 저장하면 도구가 시작되지 않고 안내가 나와야 합니다.

기존 마스크의 클래스는 바꾸지 않습니다. 없는/중복/비활성 클래스나 지원되지 않는 CVAT 화면에서는 실행을 멈춥니다. 새로운 도구 호출 중에 현재 마스크를 저장하거나 종료하지 않습니다.

설정은 해당 Chrome 프로필의 로컬 저장소에 남습니다. 다른 컴퓨터나 프로필로 자동 동기화하지 않습니다.
