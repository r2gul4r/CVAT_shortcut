# CVAT Sidebar Shortcuts 개인정보 처리 안내

적용 버전: 2.5.0 · 로컬 초안

## 처리하는 정보와 목적

CVAT 도구를 키와 휠로 조작하기 위해 현재 활성 탭의 URL이 CVAT 작업 경로인지 확인합니다. Enable한 탭에서는 필요한 사이드바 도구, 클래스 선택 메뉴와 클래스 이름, 브러시 크기 입력 상태를 기기 내에서 읽고 해당 컨트롤을 조작합니다. 단축키 입력과 휠 방향·수정키·포인터 위치는 일시적으로 확인합니다. 텍스트 입력 중의 키와 IME 조합은 실행에서 제외하며, 입력 내용이나 키 입력 기록을 저장하지 않습니다.

Mac 표시를 위해 Chrome이 제공하는 기본 플랫폼 이름을 기기 내에서 확인합니다. 이를 저장하거나 외부로 보내지 않습니다.

사용자가 연결 상태 화면에서 '측정 시작' 또는 '이 CVAT 서버에서 자동 측정'을 켜면 해당 Job 탭에서 같은 CVAT 서버로 보내는 기존 API 요청의 종류, 시작·완료 시각, 소요 시간, HTTP 상태·네트워크 오류 분류를 로컬에서 처리합니다. URL은 대상 서버와 요청 종류를 판별할 때만 사용하며 전체 URL·쿼리·본문·응답 내용·인증 헤더·이미지를 기록하지 않습니다. 별도 점검 요청이나 통계 외부 전송은 없습니다.

연결 상태 화면은 Chrome이 제공하는 온라인·오프라인 여부를 기기 안에서 표시합니다. 측정 중인 Job 탭에는 연결 변경 이벤트 수신과 일시적인 오류 알림을 위한 로컬 스크립트를 삽입합니다. Wi-Fi 신호 세기·SSID·주변 무선 네트워크 목록을 수집하지 않습니다. 연결 확인을 위한 추가 네트워크 요청도 보내지 않습니다.

사용자가 붙여넣기 반복을 시작하면 현재 Job과 프레임 번호, 프레임 준비 여부, CVAT 내부 클립보드 객체의 형식·라벨 ID, 현재 프레임 객체 ID 목록, 미리보기 준비 여부를 작업 페이지 안에서 일시적으로 확인합니다. 객체 좌표·마스크 픽셀·속성·이미지는 추출하지 않으며 위 상태를 저장하거나 외부로 보내지 않습니다. 실행 키만 기존 단축키 설정에 저장합니다. 운영체제 클립보드 내용은 읽지 않습니다. 매크로는 CVAT의 붙여넣기 키·왼클릭·다음 프레임 키를 전달하며 저장 버튼을 누르지 않습니다. CVAT 자체 자동 저장이 켜져 있다면 CVAT의 기존 설정에 따라 저장될 수 있습니다.

## 저장·보관·삭제

사용자가 검수 탭을 열거나 목록을 새로고침하면 현재 CVAT 서버의 Job 정보와 라벨 목록을 조회합니다. 전체 프레임 검사를 누르면 같은 서버에서 프레임 메타데이터와 저장된 주석을 GET으로 조회합니다. 현재 로그인 세션은 브라우저가 기존 서버에 전달하며 확장이 인증정보를 추출하거나 저장하지 않습니다. 주석 응답의 라벨 ID, Shape 프레임, Track 키프레임과 Outside를 기기 안에서 분석합니다. API 응답에 포함된 좌표·마스크·속성은 저장하거나 외부로 전송하지 않습니다. 이미지 API는 호출하지 않습니다. 저장 여부·현재 프레임·그리기 상태를 화면에서 확인하고, 요청한 프레임 이동은 CVAT의 기존 입력칸으로 처리합니다.

검수의 필수 라벨 ID와 마지막 결과(라벨 이름·ID·대표색·타입, 누락 프레임, Job·Task ID, 검사 시각·저장 버전·범위·개수)는 서버 origin과 Job 경로를 키로 `chrome.storage.local`에 보관합니다. 다시 검사하면 결과를 교체하고, 선택 라벨을 바꾸면 이전 결과를 지웁니다. 확장을 제거하면 함께 삭제됩니다. 사용자가 결과 복사·CSV 저장을 누를 때 해당 결과가 로컬 클립보드나 다운로드 파일로 제공됩니다.

사용자가 자동 측정을 켠 CVAT 서버 origin(프로토콜·호스트·포트) 목록은 `chrome.storage.local`에 저장하며 자동 측정 체크를 해제하거나 확장을 제거할 때 삭제됩니다. 자동 시작은 허용한 서버의 Job 화면에만 적용합니다. 요청별 통계는 여전히 세션에만 저장하며 자동 설정과 함께 영구 보관하지 않습니다. 현재 탭에서 잠시 끈 상태는 탭 ID와 서버 origin·Job 경로로 `chrome.storage.session`에만 기억하고, 다음 새로고침·다른 Job 이동·탭 종료 또는 브라우저 재시작 시 해제합니다.

오류 알림 사용 여부는 chrome.storage.local에 저장합니다. 중복 알림을 줄이기 위한 알림 종류·시각과 페이지 연결 식별자는 측정 세션에만 보관하며 측정 종료 시 삭제합니다.

도구·라벨 단축키, 기본 클래스 이름, 화면 이동·휠 설정 및 라벨 오버레이 설정은 해당 Chrome 프로필의 `chrome.storage.local`에 저장합니다. 다른 기기나 프로필과 동기화하지 않습니다. 사용자가 변경하거나 확장을 제거할 때까지 유지됩니다. 팝업의 해제는 해당 단축키를 지웁니다. 전체 설정은 확장을 제거하면 삭제됩니다. Chrome 프로필을 직접 복사하거나 백업하는 경우에는 그 환경의 보관 정책이 적용될 수 있습니다.

연결 상태 통계는 탭 ID·CVAT 서버 origin·현재 Job 경로와 함께 `chrome.storage.session`에만 보관합니다. 최근 5분의 완료 요청 최대 300건, 진행 요청 최대 300건으로 제한합니다. 새로고침·다른 Job 이동·탭 종료·측정 끄기에서 삭제되며 브라우저 재시작 후 영구 보관하지 않습니다. 원본 요청 데이터는 저장하지 않습니다.

현재 작업에서 사용 가능한 전체 클래스 이름과 대표색 목록은 팝업에서 선택할 수 있도록 일시적으로 읽습니다. 사용 여부나 객체 수와 관계없이 등록된 클래스를 표시합니다. 이 전체 목록은 저장하거나 전송하지 않습니다.

전체 탭 URL, 브러시 입력 상태, 포인터 위치와 이벤트 이력은 지속 저장하지 않습니다. 서버 origin·Job 경로와 사용자가 선택한 라벨은 위에 설명한 자동 측정·검수 설정 및 결과 보관에만 사용합니다.

## 외부 전송·공유

확장에는 광고, 분석/추적, 원격 코드, 이미지 읽기·픽셀 접근·스크린샷·업로드 기능이 없습니다. 검수에 필요한 저장된 주석은 사용자가 보고 있는 CVAT 서버에서 읽어 기기 내에서 처리합니다. 개발자나 제3자 서버에 이미지·주석·계정 정보·검사 결과를 전송·판매·공유하지 않습니다. 연결 상태 측정은 기존 요청의 통계만 관찰하며 검수 조회와 별개입니다.

확장이 시작하는 Interact 등 CVAT의 정상 기능은 이후 사용자의 조작에 따라 CVAT가 원래 구성한 AI 모델이나 서버를 사용할 수 있습니다. CVAT 자체의 처리·저장 통신은 이 확장과 별도이며 사용 중인 CVAT 서비스의 정책을 따릅니다. Chrome Web Store의 설치·업데이트 및 Google의 서비스 데이터 처리도 이 확장 자체의 통신과 별도입니다.

## 접근 범위

기본 권한은 activeTab, scripting, storage입니다. webRequest와 HTTP/HTTPS 호스트 접근은 선택 권한으로 선언하며, 연결 상태 화면에서 측정 시작 또는 자동 측정을 켤 때 현재 CVAT 호스트 하나만 허용을 요청합니다. 설치 시 모든 사이트 접근을 요구하지 않습니다. Chrome의 호스트 권한은 같은 호스트의 여러 포트를 포함하지만 실제 측정은 선택한 탭의 정확한 origin(포트 포함)으로 제한합니다. 허용한 사이트 권한은 Chrome에 유지되며 확장 관리의 사이트 액세스에서 철회할 수 있습니다. 측정 종료는 통계를 지우고, 사이트 권한 자체는 유지합니다. 연결 상태용 서비스 워커는 사용자가 팝업에서 측정을 켠 현재 Job 탭의 같은 서버 요청만 관찰하며, 요청을 변경하거나 차단하지 않습니다. 단축키 일시정지와 연결 상태 측정은 독립적입니다. 연결 상태는 팝업의 측정 끄기로 종료하며, 수동 모드에서는 새로고침·다른 Job 이동 후 다시 켜야 합니다. 자동 측정을 선택한 서버에서는 작업 화면 로드 후 다시 시작합니다. 측정 끄기는 현재 탭을 잠시 끄며, 자동 측정 체크 해제는 해당 서버의 모든 열린 측정과 자동 시작을 끕니다.

검수는 기존 activeTab·scripting·storage 권한을 사용하며 새로운 필수 권한은 추가하지 않습니다. 정보는 공개한 CVAT 도구 조작, 사용자 본인의 연결 상태 표시, 필수 라벨 누락 검수 목적에만 사용합니다. 광고, 별도 분석, 판매 또는 기능과 무관한 용도로 사용하지 않습니다.
