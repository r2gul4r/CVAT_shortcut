# Chrome Web Store 입력용 문구 초안

## 2.3.0 추가 기능 및 권한 안내

- **내 CVAT 연결 상태**: 팝업 상단의 단축키 / 연결 상태 화면 전환을 제공합니다. 통계는 팝업 안에서 확인하고 작업 화면에는 연결 상태 오버레이를 띄우지 않습니다. 측정을 켜면 F12 없이 현재 작업 탭의 기존 API 요청을 관찰합니다. 응답 정상·지연·오류·로그인 문제·측정 없음을 구분하고 종류별 중앙값과 오류 건수를 표시합니다.
- 추가 서버 요청·외부 전송은 없습니다. 원본 URL·요청/응답 본문·이미지·인증정보를 저장하지 않습니다. 통계는 브라우저 세션에만 보관하며 새로고침·탭 이동·종료·측정 끄기에서 삭제합니다.
- `webRequest`: 사용자가 켠 탭의 요청 시간과 HTTP/연결 오류를 읽기 전용으로 관찰합니다. 요청 감시와 현재 CVAT 호스트 접근을 선택 권한으로 요청합니다. 허용한 사이트 권한은 Chrome 확장 관리에서 철회할 때까지 유지되며, 측정은 직접 켠 Job 탭에만 적용됩니다.
- `storage`는 기존 설정 저장 외에 `storage.session`의 제한된 연결 상태 통계 보관에도 사용합니다. 상세 내용은 [개인정보 처리 안내](PRIVACY-KO.md)를 따릅니다.
- 아래 기존 소개 문구는 이전 버전 초안입니다. 실제 게시 전 현재 기능과 위 권한 안내를 함께 반영하세요.

## 이름

CVAT Sidebar Shortcuts

## 짧은 설명

CVAT AI·새 마스크 도구 단축키, 기본 클래스 선택, Alt/Option·Shift 휠 브러시 크기 조절.

## 상세 설명

CVAT에서 AI 도구와 새 마스크 브러시를 원하는 단축키로 시작하세요.

- 팝업에서 Assign / Change / Clear로 단축키를 설정합니다. 중복 키는 경고하고, 설정은 이 컴퓨터의 Chrome 프로필에 저장합니다.
- 새 객체의 기본 클래스 이름을 지정합니다. AI는 클래스 확인 후 Interact, 새 마스크는 Shape를 한 번 시작합니다. 기존 객체의 클래스는 변경하지 않습니다.
- 활성 Brush/Eraser에서 Alt/Option 또는 Shift와 휠을 함께 사용하면 크기가 한 단계마다 1씩 바뀝니다. 생성·기존 마스크 편집 모두 같은 크기 입력을 사용합니다.
- Windows와 macOS용 Chrome을 대상으로 합니다. Mac에서는 Option과 Cmd 이름을 표시하며 Ctrl과 Cmd를 구분합니다.
- 텍스트 입력, 한글/IME 조합, 비활성 도구, 지원되지 않는 화면에서는 실행하지 않습니다. Ctrl/Cmd 휠과 핀치 확대, 일반 스크롤은 유지합니다.
- 사용자가 Enable을 누른 CVAT 작업 탭에서 작동합니다. 모든 사이트에 자동으로 삽입되는 스크립트는 없습니다.

고정 단축키는 없습니다. 브라우저/OS/CVAT의 기존 단축키와 겹치지 않는 키를 선택하세요. 지원 여부는 CVAT 화면 구조에 따라 달라질 수 있으며, 대상 도구나 정확한 클래스 이름을 확인할 수 없으면 실행을 멈춥니다. 기본 클래스의 초기값은 obstacle이며 실제 작업 클래스 이름으로 변경할 수 있습니다.

팝업의 충돌 가능성 안내는 Chrome/OS 예약 키에 관한 것이며 CVAT 사용자 설정의 자동 탐지 기능이 아닙니다. CVAT Settings → Shortcuts에서 본인이 지정한 키를 확인하세요. 확장이 처리한 키는 반복·일반 release까지 후속 핸들러 전달을 막지만, 입력/IME·그리기 중·지원되지 않는 상태의 키는 CVAT의 원래 동작으로 통과할 수 있습니다.

확장 자체는 이미지를 읽거나 캡처·업로드하지 않습니다. 분석 도구, 광고, 외부 서버 통신이 없습니다. 현재 탭 URL, 필요한 도구/클래스/크기 컨트롤 상태와 입력 이벤트는 기능 수행을 위해 기기 안에서 일시 처리하며, 선택한 설정만 로컬에 저장합니다. CVAT의 기존 AI 처리·저장 통신은 해당 CVAT 서비스의 동작과 정책을 따릅니다.

CVAT의 공식 제품이 아닌 독립적인 보조 확장입니다.

## 검증 상태 문구 — 배포 직전 갱신

Windows Chrome에서 가상 CVAT 화면을 이용한 회귀 검증을 완료했습니다. Mac 관련 검증은 Windows Chrome에서 플랫폼 정보와 입력을 모의한 결과이며, 실제 Mac 기기 검증은 아직 완료하지 않았습니다. 실제 Mac 개인 테스트를 마친 뒤에만 해당 기기의 지원 확인 문구를 추가하세요.

## 단일 목적

CVAT 마스크 주석 작업에서 초기 도구 호출·기본 클래스 선택·브러시 크기 조절을 사용자가 지정한 키와 휠로 수행하도록 돕습니다.

## 권한 설명

| 권한 | 실제 사용 목적 |
|---|---|
| activeTab | 사용자가 확장 팝업을 열었을 때 현재 탭 URL을 확인하고, Enable을 선택한 CVAT 작업 탭에 일시 접근합니다. |
| scripting | Enable 버튼으로 요청한 탭에 포함된 로컬 스크립트를 격리된 실행 환경으로 삽입합니다. |
| storage | 단축키, 기본 클래스 이름, 휠 사용 여부와 수정키 선택을 Chrome 로컬 저장소에 유지합니다. |

호스트 권한, tabs 권한, 이미지 캡처 권한, 외부 서버 접근 권한은 없습니다. 원격 코드를 실행하지 않습니다.

## 개인정보 공개 입력 메모

외부 서버나 개발자에게 보내는 데이터는 없습니다. 다만 기기 내에서 처리되는 웹사이트 컨트롤 정보와 입력 이벤트, 저장되는 사용자 설정은 [PRIVACY-KO.md](PRIVACY-KO.md)의 설명대로 공개해야 합니다. 스토어 대시보드의 최신 질문에서 로컬 처리도 포함하는 항목인지 확인하여 웹사이트 콘텐츠·사용자 입력 처리 사실을 일치시켜 작성하세요. 대시보드 선택값을 자동 입력하거나 인증하지 않았습니다. 실제로 하지 않는 방문기록 추적·키 입력 기록·이미지 수집을 한다고 작성하지 마세요.

Chrome은 [최소 권한과 실제 데이터 사용 공개](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)를 요구합니다.
